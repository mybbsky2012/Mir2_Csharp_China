一、这份文档怎么用

1.1 这个文件在哪、谁在读

服务端每次启动（以及界面上点「重新加载配置」时）会读取 Configs\Setup.ini，把每一项灌进 Settings 类的静态字段。路径由 Settings.cs 里的 ConfigPath 决定，写死为程序目录下的 Configs，不跟 ini 放在一起也不会被读到。

解析器是 Shared/Functions/IniReader.cs。它有三个必须知道的行为：

键名当前值默认说明
段名与键名严格区分大小写——比对用的是 String.CompareOrdinal，[General] 写成 [general] 或 General 就会整段失效，且不报错，直接退回默认值。
读不到就静默用默认值，并顺手写回文件——ReadXxx(section, key, Default, writeWhenNull = true)：键缺失或值非法时，取代码里的默认值，然后把这个默认值追加写进 Setup.ini。所以服务端跑过一次后，文件里会多出一批你没写过的键。
布尔值只认 True / False——bool.TryParse 不接受 1 / 0 / yes / no / 开 / 关。写 1 会被当成非法值，直接回落默认值（多数默认是 False），这是最常见的「改了没反应」。

另外两点：值里不要再出现等号（解析按第一个 = 切分，后面的部分会被截断）；注释行统一用分号开头，且注释行不要写等号。

1.2 改完怎么生效

绝大多数项在「重新加载配置」或重启服务端后生效，不需要重新编译。有几类例外：网络监听类（Port、IPAddress、StartHTTPService、HTTPIPAddress、HttpTransport、资源服务相关）在服务进程启动时绑定端口，必须重启服务端；MainUser 上限、线程数同理。

还有一类是「客户端也读」的：Port、MaxResolution 由客户端 Configs\Setup.ini 的同名项配合，只改服务端不改客户端会出现连不上或被压分辨率。

三、[Network] 网络与 HTTP

3.1 连接与人数

键名当前值默认说明
IPAddress0.0.0.0127.0.0.1游戏端口监听地址。0.0.0.0 = 所有网卡（对外开服）；127.0.0.1 = 只允许本机连（配合中转/测试）。
Port70007000游戏主端口，登录与游戏共用。客户端 Configs\Setup.ini 的 Port 必须一致。【注意】改端口后要同步开防火墙入站规则。
TimeOut30000—连接超时（毫秒）。30000 = 30 秒没响应就断开；网络抖动大的服可以放到 60000。
MaxUser500—同时在线人数上限（含假人）。假人 300 的话，这个值至少要比「真人预期峰值 + 300」大。
MaxIP5—同一 IP 允许同时在线的角色数。网吧/公司网要放大；想防多开就调小。
MaxPacket50—收包上限。【注意】口径是「5 秒窗口内累计收到的数据包个数」，超过就判定为刷包外挂：断线并封该 IP 24 小时。50 相当于平均每秒 10 包，真人走位快、连招密时容易误判，建议 100~150。

HTTPQueryKey—账号查询接口 /accountinfo 的密钥（10~30 位）。留空 = 该接口一律拒绝；网页端调用时带 &key=此值。

十四、速查：问题项与未写入项

14.1 一眼看出的问题项

按代码实际行为核对这份样本文件，下面几项要么是非法值、要么与直觉相反，建议开服前逐条确认：

键名当前值默认说明
DropRate = 0——除零后溢出，等效「几乎不掉落」。应改为 1（原版）或目标倍数。
HighLevelExpRate = 90——是倍数不是百分比。90 表示 60 级以上额外 90 倍，叠加 ExpRate 200 后是 18000 倍。若本意「额外 90%」，应写 1.9。
TameSuccessRate = 100——必定招中。所有可招的怪一次就到手，包括本来极难招的。
ItemTimeOut = 2——地上物品两分钟消失，远低于默认 30 分钟。玩家打完一波怪回头捡，常常已经没了。
MaxPacket = 50——5 秒 50 包，高强度操作下可能被误判刷包并封 IP 24 小时。建议 100~150。
RelogDelay / Language / RequireStoragePassword / MaxBossTames / MonsterRecall* / Mon4xxB* / HeroName——全部已失效，改了没有任何效果，可以删掉减少干扰。
