; ============================================================
;  泡点（含英雄经验）示例脚本
;
;  放置位置：服务端运行目录下的 Envir\NPCs\
;  使用方法：在 NPC 配置中把本脚本关联到某个 NPC，玩家点开即进入 [@MAIN] 页
;
;  用到的命令：
;    SETLOOPTIMER   名称 间隔秒数 触发标签   开启循环定时器，每 N 秒执行一次该标签
;    EXPIRETIMER    名称                     关闭同名循环定时器
;    CHECKLOOPTIMER 名称                     判断循环定时器是否开启（条件命令）
;    GIVEEXP        数值                     给角色加经验
;    GIVEHEROEXP    数值                     给英雄加经验（新增）
;
;  GIVEHEROEXP 说明：
;    1. 只对【已召唤、且未死亡】的英雄生效；英雄没召出来或已死亡时，
;       这一行会被静默跳过，不报错，角色经验照常发放
;    2. 数值是纯数值，不加百分号、不加逗号，写 10000 不要写 10,000
;    3. 英雄自身带「经验增长数率」属性时，会在此基础上再加成
;       （和打怪掉经验走同一套算法）
;    4. 不受服务端全局经验倍率 ExpRate 影响，脚本给多少就是多少
;
;  注意事项：
;    1. 触发标签必须写在【同一个脚本文件】里；[] 可以省略
;    2. 定时器按玩家独立计时，玩家下线自动清除，不会离线泡点
;    3. 定时器触发是静默的，被触发的页面里不要写 #SAY，
;       用 LOCALMESSAGE 提示玩家
; ============================================================


[@MAIN]
#SAY
欢迎来到泡点使者处。\ \
保持在线，每隔 60 秒角色与英雄可同时获得经验。\ \
（英雄需要先召唤出来才能获得经验）\ \

<开始泡点/@开始> <停止泡点/@停止> <查看状态/@状态> <离开/@EXIT>


[@开始]
#IF
CHECKLOOPTIMER 泡点
#ACT
LOCALMESSAGE "你已经在泡点了。" Hint
BREAK

#IF
#ACT
SETLOOPTIMER 泡点 60 泡点奖励
LOCALMESSAGE "泡点已开启：每 60 秒发放一次经验。" Hint


[@停止]
#IF
CHECKLOOPTIMER 泡点
#ACT
EXPIRETIMER 泡点
LOCALMESSAGE "泡点已停止。" Hint
BREAK

#IF
#ACT
LOCALMESSAGE "你当前没有在泡点。" Hint


[@状态]
#IF
CHECKLOOPTIMER 泡点
#ACT
LOCALMESSAGE "泡点正在进行中。" Hint
BREAK

#IF
#ACT
LOCALMESSAGE "泡点未开启。" Hint


; ------------------------------------------------------------
;  定时器每 60 秒触发一次的内容（静默执行，不要写 #SAY）
;  这里按角色等级分两档，角色与英雄各发一份，数值自行调整
; ------------------------------------------------------------
[@泡点奖励]
#IF
LEVEL < 60
#ACT
GIVEEXP 10000
GIVEHEROEXP 10000
LOCALMESSAGE "泡点奖励：角色与英雄各获得 10000 点经验。" Hint
#ELSEACT
GIVEEXP 20000
GIVEHEROEXP 20000
LOCALMESSAGE "泡点奖励：角色与英雄各获得 20000 点经验。" Hint


; ------------------------------------------------------------
;  变体：英雄经验只给角色的一半

; #IF
; LEVEL < 60
; #ACT
; GIVEEXP 10000
; GIVEHEROEXP 5000
; LOCALMESSAGE "泡点奖励：角色获得 10000 点，英雄获得 5000 点经验。" Hint
; #ELSEACT
; GIVEEXP 20000
; GIVEHEROEXP 10000
; LOCALMESSAGE "泡点奖励：角色获得 20000 点，英雄获得 10000 点经验。" Hint
