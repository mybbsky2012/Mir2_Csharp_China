; ============================================================
;  羽化登仙 · 渡劫转生任务（仙官 NPC）
;
;  放置位置：服务端运行目录下的 Envir\NPCs\羽化登仙.txt
;  NPC 登记：在 Envir\NPCs\npc.txt 中加一行（格式按你现有 npc.txt 列）：
;      羽化登仙,3,333,333,渡劫仙官
;  名单文件：Envir\羽化名单\{渡劫名单,仙名单,魔名单}.txt
;      （文件不存在时脚本会自动创建，但建议随包预建）
;  属性奖励：Configs\BuffSystem.ini 中的自定义 BUFF「羽化登仙」「重塑入魔」
;
;  玩法（参考传奇经典渡劫转生流）：
;    1. 渡劫：等级 ≥ 60 且缴 500 万金币 → 进入渡劫名单（一生一次）
;    2. 羽化登仙：渡劫后缴 仙侣石×10 → 永久 BUFF「羽化登仙」+ 全服公告
;    3. 重塑入魔：渡劫后缴 魔晶石×10 → 永久 BUFF「重塑入魔」+ 全服公告
;    4. 仙魔互斥，选择后不可更改；BUFF 防重复，名单防刷
; ============================================================


[@MAIN]
#SAY
人道渺渺，仙道莽莽，鬼道乐兮。\ \
当人生门，仙道贵生，鬼道贵终。\ \
飘飘乎如遗世独立，羽化而登仙。\ \ \
道友若已修至一甲子（60级），可来此<经历渡劫/@开始渡劫>。\ \
渡劫之后仙魔殊途，须择其一——\ \

<羽化登仙/@羽化登仙> <重塑入魔/@重塑入魔> <打听详情/@渡劫说明> <离开/@EXIT>


[@渡劫说明]
#SAY
【渡劫】等级达到 60 级，缴付 500 万金币作引雷之资，方可渡劫。\ \
渡劫一生只有一次，渡过方可择路仙魔。\ \ \
【仙·羽化登仙】收 仙侣石×10 ——\ \
攻击/魔法/道术 +50，防御/魔御 +30，永久生效。\ \ \
【魔·重塑入魔】收 魔晶石×10 ——\ \
攻击速度 +5，生命 +1000，魔法 +1000，永久生效。\ \ \
仙魔互斥，一旦选择，此生不可更改。\ \

<返回/@MAIN> <离开/@EXIT>


; ---------- 渡劫 ----------

[@开始渡劫]
#IF
CHECKNAMELIST .\Envir\羽化名单\渡劫名单.txt
#ACT
GOTO @已渡劫
BREAK

#SAY
你尚未渡劫。\ \
天劫无情，需等级 60 级以上，并备足 500 万金币作引雷之资。\ \
渡劫时九霄雷落，生死自负。\ \

<正式渡劫/@正式渡劫> <返回/@MAIN> <离开/@EXIT>


[@正式渡劫]
#IF
LEVEL > 59
CHECKGOLD > 4999999
#ACT
TAKEGOLD 5000000
ADDNAMELIST .\Envir\羽化名单\渡劫名单.txt
LOCALMESSAGE "九霄雷落！你挺过了天劫，从此踏入渡劫之境。" Announcement
BREAK

#ELSESAY
天劫无情，你尚未准备妥当——\ \
需等级 60 级以上，且身上备足 500 万金币。\ \

<返回/@MAIN> <离开/@EXIT>


[@已渡劫]
#SAY
你已渡过天劫，真元激荡，正待抉择仙魔之路。\ \

<羽化登仙/@羽化登仙> <重塑入魔/@重塑入魔> <离开/@EXIT>


; ---------- 仙路 · 羽化登仙 ----------

[@羽化登仙]
#IF
CHECKBUFF 羽化登仙
#ACT
GOTO @已是仙身
BREAK

#IF
CHECKBUFF 重塑入魔
#ACT
GOTO @仙魔互斥
BREAK

#SAY
若要羽化登仙，需集齐 <仙侣石>×10。\ \
仙侣石散落于各大妖王巢穴，有缘者得之。\ \
成仙之后：攻击/魔法/道术 +50，防御/魔御 +30，永久生效。\ \

<交出仙侣石/@仙路缴石> <返回/@MAIN> <离开/@EXIT>


[@仙路缴石]
#IF
CHECKNAMELIST .\Envir\羽化名单\渡劫名单.txt
CHECKITEM 仙侣石 10 0
#ACT
TAKEITEM 仙侣石 10 0
GIVEBUFF 羽化登仙 0 True True False
ADDNAMELIST .\Envir\羽化名单\仙名单.txt
LOCALMESSAGE "白日飞升！恭喜你位列仙班，从此逍遥天地间！" Announcement
GLOBALMESSAGE "飘飘乎如遗世独立，羽化而登仙！恭喜玩家 %USERNAME 渡劫飞升，位列仙班！" Announcement
BREAK

#ELSESAY
未能成行——\ \
你可能尚未渡劫，或身上仙侣石不足 10 颗（须放于背包）。\ \

<返回/@MAIN> <离开/@EXIT>


[@已是仙身]
#SAY
道友早已位列仙班，何须再问凡尘事？\ \
愿你逍遥天地，长生久视。\ \

<离开/@EXIT>


; ---------- 魔路 · 重塑入魔 ----------

[@重塑入魔]
#IF
CHECKBUFF 重塑入魔
#ACT
GOTO @已是魔身
BREAK

#IF
CHECKBUFF 羽化登仙
#ACT
GOTO @仙魔互斥
BREAK

#SAY
若要重塑入魔，需集齐 <魔晶石>×10。\ \
魔晶石汲取怨念而生，见于凶地魔窟。\ \
入魔之后：攻击速度 +5，生命 +1000，魔法 +1000，永久生效。\ \

<交出魔晶石/@魔路缴石> <返回/@MAIN> <离开/@EXIT>


[@魔路缴石]
#IF
CHECKNAMELIST .\Envir\羽化名单\渡劫名单.txt
CHECKITEM 魔晶石 10 0
#ACT
TAKEITEM 魔晶石 10 0
GIVEBUFF 重塑入魔 0 True True False
ADDNAMELIST .\Envir\羽化名单\魔名单.txt
LOCALMESSAGE "血气滔天！你重塑魔身，从此以杀证道！" Announcement
GLOBALMESSAGE "修罗现世，血染苍穹！玩家 %USERNAME 重塑入魔，以杀证道，请各位小心！" Announcement
BREAK

#ELSESAY
未能成行——\ \
你可能尚未渡劫，或身上魔晶石不足 10 颗（须放于背包）。\ \

<返回/@MAIN> <离开/@EXIT>


[@已是魔身]
#SAY
你魔气冲天，早入魔道，何须再来?\ \
以杀止杀，魔亦有道。\ \

<离开/@EXIT>


[@仙魔互斥]
#SAY
仙魔殊途，道不同不相为谋。\ \
你既已择路，此生不可再改——莫要痴心妄想。\ \

<离开/@EXIT>
