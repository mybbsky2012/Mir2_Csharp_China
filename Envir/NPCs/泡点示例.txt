; ============================================================
;  泡点（循环定时器）示例脚本
;
;  放置位置：服务端运行目录下的 Envir\NPCs\
;  使用方法：在 NPC 配置中把本脚本关联到某个 NPC，玩家点开即进入 [@MAIN] 页
;
;  新增的三个脚本命令：
;    SETLOOPTIMER   名称 间隔秒数 触发标签   开启循环定时器，每 N 秒执行一次该标签
;    EXPIRETIMER    名称                     关闭同名循环定时器
;    CHECKLOOPTIMER 名称                     判断循环定时器是否开启（条件命令）
;
;  注意事项：
;    1. 触发标签必须写在【同一个脚本文件】里；[] 可以省略，
;       程序会自动补全为 [@标签]，例如写「泡点奖励」等价于「[@泡点奖励]」
;    2. 触发标签【不需要】任何按钮跳到它，也不需要写进 [@MAIN] 的按钮列表；
;       它只由定时器在后台调用。（旧版本会因为「没有按钮指向」而静默失效，已修复）
;    3. 定时器按玩家独立计时，玩家下线会自动清除，因此不会离线泡点
;    4. 定时器触发时是【静默】执行的，不会弹出 NPC 对话框，
;       所以被触发的页面里不要写 #SAY，用 LOCALMESSAGE 之类的方式提示玩家
;    5. 重复执行同名 SETLOOPTIMER 会覆盖旧定时器（相当于重置计时）
; ============================================================


[@MAIN]
#SAY
欢迎来到泡点使者处。\ \
只要保持在线，每隔一段时间就能自动获得经验奖励。\ \

<开始泡点/@开始> <停止泡点/@停止> <查看状态/@状态> <离开/@EXIT>


[@开始]
#IF
CHECKLOOPTIMER 泡点
#ACT
LOCALMESSAGE "你已经在泡点了。" Hint
BREAK

#IF
#ACT
SETLOOPTIMER 泡点 60 泡点奖励
LOCALMESSAGE "泡点已开启：每 60 秒自动获得一次经验。" Hint


[@停止]
#IF
CHECKLOOPTIMER 泡点
#ACT
EXPIRETIMER 泡点
LOCALMESSAGE "泡点已停止。" Hint
BREAK

#IF
#ACT
LOCALMESSAGE "你当前没有在泡点。" Hint


[@状态]
#IF
CHECKLOOPTIMER 泡点
#ACT
LOCALMESSAGE "泡点正在进行中。" Hint
BREAK

#IF
#ACT
LOCALMESSAGE "泡点未开启。" Hint


; ------------------------------------------------------------
;  下面这一页就是定时器每 60 秒触发一次的内容，按需修改
;  （静默执行，不要写 #SAY）
; ------------------------------------------------------------
[@泡点奖励]
#IF
LEVEL < 60
#ACT
GIVEEXP 10000
LOCALMESSAGE "泡点奖励：获得 10000 点经验。" Hint
#ELSEACT
GIVEEXP 20000
LOCALMESSAGE "泡点奖励：获得 20000 点经验。" Hint
