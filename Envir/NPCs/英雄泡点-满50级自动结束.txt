; ============================================================
;  英雄泡点脚本（英雄到 50 级自动结束）
;
;  放置位置：服务端运行目录下的 Envir\NPCs\
;  使用方法：在 NPC 配置中把本脚本关联到某个 NPC，玩家点开即进入 [@MAIN] 页
;
;  用到的命令：
;    SETLOOPTIMER   名称 间隔秒数 触发标签   开启循环定时器，每 N 秒执行一次该标签
;    EXPIRETIMER    名称                     关闭同名循环定时器
;    CHECKLOOPTIMER 名称                     判断循环定时器是否开启（条件命令）
;    GIVEHEROEXP    数值                     给英雄加经验
;    HEROLEVEL      运算符 数值              英雄等级条件（新增，如 HEROLEVEL < 50）
;
;  HEROLEVEL 说明（本版本新增的脚本条件命令）：
;    1. 写法与 LEVEL 完全一致，只是判断对象换成英雄：HEROLEVEL < 50 / >= 50 / == 45 ...
;    2. 英雄未召唤或已死亡时，条件一律按「不成立」处理（脚本不会报错）
;
;  注意事项：
;    1. 定时器按玩家独立计时，玩家下线自动清除，不会离线泡点
;    2. 定时器触发是静默的，被触发的页面里不要写 #SAY，用 LOCALMESSAGE 提示
;    3. 经验数值自行调整（本例每 60 秒 10000 点）
; ============================================================


[@MAIN]
#SAY
欢迎来到英雄泡点使者处。\ \
保持在线并召唤出英雄，每隔 60 秒英雄可获得 10000 点经验。\ \
<英雄等级达到 50 级后，泡点自动结束>。\ \

<开始泡点/@开始> <停止泡点/@停止> <查看状态/@状态> <离开/@EXIT>


[@开始]
#IF
CHECKLOOPTIMER 英雄泡点
#ACT
LOCALMESSAGE "你已经在泡点了。" Hint
BREAK

#IF
#ACT
SETLOOPTIMER 英雄泡点 60 英雄泡点奖励
LOCALMESSAGE "英雄泡点已开启：每 60 秒英雄获得 10000 点经验，满 50 级自动结束。" Hint


[@停止]
#IF
CHECKLOOPTIMER 英雄泡点
#ACT
EXPIRETIMER 英雄泡点
LOCALMESSAGE "英雄泡点已停止。" Hint
BREAK

#IF
#ACT
LOCALMESSAGE "你当前没有在泡点。" Hint


[@状态]
#IF
CHECKLOOPTIMER 英雄泡点
#ACT
LOCALMESSAGE "英雄泡点正在进行中。" Hint
BREAK

#IF
#ACT
LOCALMESSAGE "英雄泡点未开启。" Hint


; ------------------------------------------------------------
;  定时器每 60 秒触发的内容（静默执行，不要写 #SAY）
;  逻辑：
;    1. 英雄已召唤且等级 < 50 → 发经验
;    2. 英雄等级 >= 50       → 自动关定时器，泡点结束
;    3. 英雄未召唤或已死亡   → 跳过本回合，泡点继续挂着
; ------------------------------------------------------------
[@英雄泡点奖励]
#IF
HEROLEVEL < 50
#ACT
GIVEHEROEXP 10000
LOCALMESSAGE "泡点：英雄获得 10000 点经验。" Hint
BREAK

#IF
HEROLEVEL >= 50
#ACT
EXPIRETIMER 英雄泡点
LOCALMESSAGE "英雄已满 50 级，泡点自动结束。" Hint
BREAK

#IF
#ACT
LOCALMESSAGE "英雄未召唤（或已死亡），本回合经验未发放，泡点继续。" Hint
