# 羽化登仙 · 渡劫转生任务 — 部署说明

参考传奇经典"渡劫→仙魔二选一"转生玩法，结合本引擎的自定义 BUFF / 名单 / NPC 脚本系统实现。

## 一、玩法

| 阶段 | 条件 | 收益 |
|---|---|---|
| 渡劫 | 等级 ≥ 60 + 金币 500 万 | 进入渡劫名单（一生一次） |
| 羽化登仙（仙路） | 已渡劫 + 仙侣石×10 | 永久 BUFF：攻击/魔法/道术 +50，防御/魔御 +30 |
| 重塑入魔（魔路） | 已渡劫 + 魔晶石×10 | 永久 BUFF：攻击速度 +5，生命 +1000，魔法 +1000 |

- 仙魔互斥：选了仙不能再入魔，反之亦然（BUFF 拦截）。
- 防重复：BUFF 判定 + 名单文件双保险，材料每次结算即扣。
- 成仙/入魔触发全服公告（红色 Announcement），公告带玩家名。

## 二、文件清单

| 文件 | 位置（服务端运行目录） | 作用 |
|---|---|---|
| 羽化登仙.txt | Envir\NPCs\ | NPC 脚本（本包已放源码库 Envir\NPCs\） |
| 渡劫名单.txt / 仙名单.txt / 魔名单.txt | Envir\羽化名单\ | 名单（文件丢失脚本会自动重建，但建议预建） |
| BuffSystem.ini | Configs\ | 自定义 BUFF 属性（[1]羽化登仙 / [2]重塑入魔 两节） |

> ⚠️ 若运行目录已有 BuffSystem.ini，把两个 [节] 追加到文件末尾即可，**不要整份覆盖**；
> 槽位 1/2 若被占用就顺延改号（1~24），脚本按显示名"羽化登仙/重塑入魔"引用，无需改脚本。

## 三、挂载 NPC

在 Envir\NPCs\npc.txt 中加一行（列格式与你现有行一致）：

```
羽化登仙,3,333,333,渡劫仙官
```

（脚本路径 = NPCs 目录下的文件名，不带 .txt；地图/坐标自行调整）

## 四、材料物品（仙侣石 / 魔晶石）

脚本按物品名结算。若物品库中没有这两种物品，任选其一：

1. 用 GM 命令造几颗测试：`@MAKE 仙侣石`、`@MAKE 魔晶石`
2. 在物品库中正式添加（ItemType 建议"任务物品"），并放进 BOSS 掉落表。

掉落表示例（加到 Envir\Drops\ 下对应怪物文件，1/N 自调）：

```
1/50 仙侣石 1
1/50 魔晶石 1
```

## 五、数值调整速查

- 渡劫等级门槛：脚本 `LEVEL > 59`
- 渡劫金币：脚本 `CHECKGOLD > 4999999` + `TAKEGOLD 5000000`
- 材料数量：`CHECKITEM 仙侣石 10 0` / `TAKEITEM 仙侣石 10 0`（两处同步改）
- 属性数值：Configs\BuffSystem.ini 的 `Stat.xxx=数值`（支持 `基础+每级` 写法）

## 六、本次随带的引擎修复（已编译进 Server.Library.dll）

1. **GIVEBUFF 参数顺序错位修复**（NPCSegment.cs 解析端）：
   原先解析端把脚本第 3/4 参数当"可见/无限"，执行端却按"无限/可见"读，
   两端口径相反。现统一为 `GIVEBUFF 名称 时长 永久 可见 可叠加`，
   时长写 0 即永久 buff。引擎原有脚本无使用该命令者，无兼容影响。
2. **ADDNAMELIST / DELNAMELIST 名单文件保护**：文件不存在时自动创建/跳过，
   不再抛异常中断整段动作（防手滑删名单崩服）。

## 七、验证路径

1. 替换 Server.Library.dll → 重启（或外壳重新加载脚本）
2. GM 号测试：`@LEVEL 60` → 找仙官渡劫 → `@MAKE 仙侣石 10` → 羽化登仙
3. 确认：金币被扣、公告出现、BUFF 栏出现"羽化登仙"且属性生效（再点一次提示"早已位列仙班"）
