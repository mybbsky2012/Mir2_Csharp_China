# 万效符 / 灵魂火符(万效) 范围调整说明

日期：2026-10-17
涉及技能：万效符、万效符-秘籍、灵魂火符(万效)、灵魂火符(万效-秘)

---

## 一、两个现象，两个根因

### 现象 1：明明周围有几只怪，只飞出一张符

`Server/MirObjects/HumanObject.cs` 里 `SoulFireballPlus()` 选副目标的方式是：

```csharp
//旧：以「主目标」为圆心，5×5（半径只有 2 格）
foreach (var ob in GetHostileInSquare(target.CurrentLocation, 5))
```

- 圆心是**被打的那只怪**，不是自己；
- `GetHostileInSquare(centre, size)` 里 `r = (size - 1) / 2`，所以 5×5 实际只有**半径 2 格**。

只要怪不是挤在主目标身边 2 格内，副目标一个都补不进来 → 永远只有主目标那一张符。

### 现象 2：升格后锁不到远处的怪

射程判断有两处，但**用的都不是升格技能自己的数据**：

| 位置 | 用的 Range | 说明 |
|---|---|---|
| 客户端 `GameScene.cs` 施法前 | `magic.Range` = **灵魂火符**的 Range | 升格替换发生在距离检查**之后**，检查时还是普通版 |
| 服务端 `HumanObject.Magic()` | 升格时 `magic = GetMagic(Spell.SoulFireBall)` | 结算数据故意沿用普通版，射程跟着被换回普通版 |

结果：把 `灵魂火符(万效)` 的 `Range` 调大**不会有任何效果**（这是最容易踩的坑）。

---

## 二、改了什么

### 1. 副目标：改为以施法者为圆心，半径 6 格（原 2 格，+4）

```csharp
private const int SoulFireBallPlusSpreadSize = 13;   // 13×13 → 半径 6 格

var targets = new List<MapObject> { target };
var candidates = GetHostileInSquare(CurrentLocation, SoulFireBallPlusSpreadSize);
candidates.Sort(...);   // 按离自己的距离排序，近的优先
```

- 主目标永远第一张，其余按距离由近到远补，最多 3 只（秘籍 6 只）；
- 圆心从「主目标」改成「自己」，玩家看到的「范围里有几只怪」就能真打几只。

### 2. 服务端射程：升格后按两者较大值放行

```csharp
int castRange = magic != null ? magic.Info.Range : 0;
...
if (talismanUpgraded)
{
    magic = GetMagic(Spell.SoulFireBall) ?? magic;   // 结算仍用普通版
    UserMagic upgradedMagic = GetMagic(spell);
    if (upgradedMagic != null && upgradedMagic.Info.Range > castRange)
        castRange = upgradedMagic.Info.Range;        // 射程单独放宽
}
```

以后再调 `灵魂火符(万效)` 的 Range 就不会被无声吞掉了。

### 3. 数据：Range 9 → 13（+4 格）

| 技能 | 原 | 现 |
|---|---|---|
| 灵魂火符 | 9 | **13** |
| 灵魂火符(万效) | 9 | **13** |
| 灵魂火符(万效-秘) | 9 | **13** |

**为什么必须连普通版一起改**：客户端锁怪用的是「灵魂火符」这一条的 Range（见上表），只改万效版，客户端会先报「目标距离太远」。所以现在**普通灵魂火符的射程也从 9 变成 13**——这是本次唯一一处波及普通技能的改动。

## 六、补充（13:32）：去掉「请先选择一个可攻击的目标」

### 为什么这句提示特别容易在灵魂火符上刷屏

`HumanObject.Magic()` 解析目标时是写死的：

```csharp
target = FindObject(targetID, 10);   //只在自己周围 10 格内找
```

射程改成 13 后，**11~13 格的目标根本解析不出来** → `target == null` → 万效版弹提示、原地不动。这不是玩家没瞄准，是服务端没找到。

### 改了两处

1. `SoulFireballPlus()`：去掉提示，无目标时静默返回，与普通灵魂火符一致（普通版本来就不提示）。
2. `Magic()`：目标搜索半径改为 `Math.Max(10, castRange)`，与技能射程对齐。射程 13 的技能现在能真正取到 11~13 格的目标。

强击-秘籍、影华连击仍保留该提示（未改动）。
