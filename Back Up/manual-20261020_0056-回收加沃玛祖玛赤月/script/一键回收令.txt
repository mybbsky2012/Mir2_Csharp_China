;=====================================================================
; 一键回收令 —— 一键回收（按套装）
;---------------------------------------------------------------------
; 三种触发方式，进的都是同一个菜单：
;   1) 背包里双击「一键回收令」物品（特殊消耗品，Shape = 80）
;   2) 聊天栏输入  @一键回收
;   3) 背包界面顶部的「一键回收」按钮（客户端内置，发的就是 @一键回收）
;
; 回收逻辑在服务端代码里（Server\MirObjects\RecycleManager.cs），本脚本只负责
; 菜单和确认：
;   · 只收背包（含腰带 0~5 格），装备栏、仓库、精炼台一律不碰
;   · 只收玩家选中的那一个套装，别的套装不动
;   · 回收价 = 物品数据库原价 × 数量，不打折
;   · 绑定「不可出售」的物品自动跳过
;   · 物品直接销毁，不进商店的「买回」列表
;
; ★ 想增减可回收的套装：删掉对应的 [@回收N] 与 [@执行N] 两页，再把目录页里
;   那条按钮删掉即可（N 是 ItemSet 枚举值）。
; ★ RECYCLE 后面那个参数必须和 Shared\Enums.cs 里 ItemSet 的枚举名一字不差。
;=====================================================================


;;------------ 物品触发：一键回收令（Shape = 80）------------
[@_UseItem(80)]
#ACT
GOTO @一键回收


;;------------ 聊天命令触发：@一键回收 ------------
[@一键回收]
#SAY
背包塞满了吧？成套的装备别一件件丢，我可以直接帮你换成金币。
回收价按物品原价算，只收背包里的东西，身上穿的、仓库里的都不动。
先选个套装分类看看：
<初级套装/@回收目录1> <中级套装/@回收目录2> <高级套装/@回收目录3> <顶级套装/@回收目录4>
<关闭/@exit>

[@回收目录1]
