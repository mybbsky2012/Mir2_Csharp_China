# GM 管理员命令 & 调试命令手册

> 来源：服务端 `Server\MirObjects\PlayerObject.cs` 命令 switch（L2124~L4305），共 **75 组命令**，逐条核对代码生成。
> 适用版本：2026-10-20 部署的 Server.Library.dll（`5c608e77`）
> 命令**不区分大小写**，参数用空格分隔；中文命令名保留中文。

---

## 一、先拿到 GM 权限

| 步骤 | 操作 |
|---|---|
| 1 | 在游戏聊天框输入 `@LOGIN` |
| 2 | 系统提示「请输入管理员密码！」 |
| 3 | **下一条聊天内容就是密码**（不会显示成命令） |
| 4 | 密码正确 → 提示「升级为游戏管理员」，标记 IsGM |

- 密码存在 `Setup.ini` 的 `[General] GMPassword`，默认值 `@9396399`，**务必改掉**
- 密码错会记录到服务端日志并提示「登录密码不正确」，一次机会
- 部分命令带 `!Settings.TestServer` 条件：配置 `TestServer=True` 时**非 GM 也能用**（测试服专用，正式服要关掉）

## 二、身份与状态开关

| 命令 | 参数 | 作用 |
|---|---|---|
| `@LOGIN` | — | 进入管理员密码验证流程 |
| `@GAMEMASTER` | — | 切换「管理员模式」/ 正常模式（GM 特殊显示） |
| `@SUPERMAN` | — | 切换**无敌**（GMNeverDie，不会死） |
| `@OBSERVER` | — | 切换观察者模式（隐身旁观） |
| `@OBSERVE <玩家名>` | 玩家名 | 直接观察指定玩家视角 |
| `@ALLOWOBSERVE` | — | 允许/禁止别人观察自己 |
| `@TOGGLETRANSFORM` | — | 暂停/恢复身上的变形外形效果 |
| `@SUMMONHERO` | — | 召唤英雄（未召出时生效，会附加职业对应「英雄灵气」BUFF） |

## 三、地图与移动

| 命令 | 参数 | 作用 |
|---|---|---|
| `@传送 <x> <y>` | 坐标 / 留空 | GM 直接传送到坐标；**不带参数=随机传送**（非 GM 用需戴传送戒指且有冷却） |
| `@MAPMOVE <地图名> [实例ID] [x y]` | 见下 | 跨地图传送，4 种用法见下 |
| `@GOTO <玩家名>` | 玩家名 | **自己**传送到该玩家身边 |
| `@RECALL <玩家名>` | 玩家名 | 把该玩家**拉到**自己身边 |
| `@MAP` | — | 显示当前地图信息（玩家也能用） |
| `@CLEARMOB [地图名]` | 地图名 / 留空 | 清空指定地图的怪物；留空=当前地图 |

**`@MAPMOVE` 的 4 种写法**

```
@MAPMOVE 3                  → 地图 3 的随机点
@MAPMOVE 3 2                → 地图 3 的第 2 个实例，随机点
@MAPMOVE 3 100 200          → 地图 3 的坐标 (100,200)
@MAPMOVE 3 2 100 200        → 地图 3 第 2 实例的 (100,200)
```

## 四、物品 / 货币 / 技能

| 命令 | 参数 | 作用 |
|---|---|---|
| `@MAKE <物品名或ID> [数量]` | 物品、数量 | 制造物品到自己背包（物品带 GM 制造标记，可堆叠超过上限自动拆多格） |
| `@GIVEGOLD <数量> [玩家名]` | 数量、玩家 | 给金币（**第一个参数是数量**，第二个才是玩家名） |
| `@GIVEPEARLS <数量> [玩家名]` | 数量、玩家 | 给珍珠 |
| `@GIVECREDIT <数量> [玩家名]` | 数量、玩家 | 给信用点 |
| `@GIVESKILL <技能名> <等级> [玩家名]` | 技能、等级、玩家 | 给技能或调等级（等级最高 3） |
| `@DELETESKILL <技能名> [玩家名]` | 技能、玩家 | 删除技能 |
| `@CLEARBAG [玩家名]` | 玩家 | **清空背包**（不留痕迹，慎用） |
| `@CLEARBUFFS` | — | 清空自己身上所有 BUFF |
| `@ADDINVENTORY` | — | 扩展背包（玩家命令，扣金币解锁） |
| `@ADDSTORAGE` | — | 扩展仓库（玩家命令，扣金币解锁） |
| `@DECO <图片索引>` | 图片号 | 在自己脚下放一个装饰物（地图持久） |
| `@HAIR [发型号]` | 发型号 | 改发型；不带参数=随机 |

## 五、人物属性

| 命令 | 参数 | 作用 |
|---|---|---|
| `@LEVEL <等级> [玩家名]` | 等级、玩家 | 调整等级 |
| `@LEVELHERO <等级> [玩家名]` | 等级、玩家 | 调整英雄等级 |
| `@CHANGECLASS <职业> [玩家名]` | 职业英文名、玩家 | 改职业（如 `Warrior` `Wizard` `Taoist`） |
| `@CHANGEGENDER [玩家名]` | 玩家 | **切换性别**（男↔女，不带参数=自己） |
| `@ADJUSTPKPOINT <点数> [玩家名]` | 点数、玩家 | 调整 PK 值 |
| `@KILL [玩家名]` | 玩家 | 杀死目标玩家（留空=自己） |
| `@DIE` | — | 自己立刻死亡（调试死亡流程用） |
| `@REVIVE [玩家名]` | 玩家 | 复活（留空=自己，满血满蓝） |
| `@SETLIGHT <亮度>` | 0~255 | 设置自身光照范围 |
| `@SETTIMER <键> <秒> <类型>` | 三个参数 | 设置客户端计时器（调试用） |
| `@SETFLAG <序号>` | 0~N | **切换**人物标记位（对 NPC 脚本 `CHECKFLAG` 有影响） |
| `@LISTFLAGS` | — | 列出当前所有已开启的标记 |
| `@CLEARFLAGS [玩家名]` | 玩家 | 清空标记位 |

## 六、怪物

| `@MOB <怪物名或ID> [数量] [散布半径]` | 怪物、数量、半径 | 在身边刷怪；半径 0=面前单点，>0=周围随机散布。**不能刷攻城怪/灵物** |

## 十四、常用组合示例

```
@LOGIN                     → 输入密码拿 GM
@SUPERMAN                  → 开无敌去测试
@MAKE 一键回收令 10        → 造 10 个回收令
@LEVEL 60 张三             → 给张三升到 60 级
@GIVEGOLD 100000 张三      → 给张三 10 万金币
@MOB 鸡 5 3                → 身边刷 5 只鸡，散布 3 格
@RECALLMOB 神兽 1 7        → 召 7 级神兽当宝宝
@MAPMOVE 0 330 330         → 传送到地图 0 坐标 (330,330)
@INFO                      → 看面前的怪/人详细数据
@RELOADNPCS                → 改完脚本热重载
@假人 reset                → 改完假人配装重生成
```

## 十五、注意事项

1. **`@MAKE` 制造的物品带 GM 标记**（`GMMade`），不会写入正常掉落体系
2. **`@GIVEGOLD` 参数顺序容易搞错**：`@GIVEGOLD <数量> [玩家名]`，数量在前
3. **`@CLEARBAG`、`@CLEARPLAYER` 类命令不可撤销**，操作前 `@BACKUPPLAYER`
4. **`@MOB` 刷不出攻城类怪物和灵物**，需要攻城 AI 请用 `@STARTCONQUEST`
5. **`@SETFLAG` 是「切换」不是「设为 1」**，重复执行会在 0/1 之间翻转
6. 改 `Setup.ini` 的 `GMPassword` 后需重启服务端，**正式服千万别用默认密码**
7. 脚本里可用 `@RELOADNPCS` 热更新，但**改了 C# 代码必须重启服务端**
