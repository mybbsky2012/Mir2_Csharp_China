# 假人系统（AI 玩家）—— 设计与使用说明

> 目标：让本来空荡荡的服务端「看起来像有 50 个人在玩」。
> 假人会在各练级地图打怪、吃药、捡装备并且换上更好的、药没了回城补给、
> 时不时发呆、偶尔冒一句聊天、还会像真人一样随机上线 / 下线。

---

## 一、总体思路

市面上的假人实现通常是「再写一个怪物 AI 冒充玩家」，代价是客户端要额外适配，
而且假人一眼就能看出来（不会换装备、不会聊天、走路是怪物那套逻辑）。

本实现反其道而行：**假人在服务端就是真正的 `PlayerObject`**。

```
                 ┌──────────────────────────┐
   真人客户端 ──► │  MirConnection(真 socket) │ ──► PlayerObject
                 └──────────────────────────┘
                 ┌──────────────────────────┐
      （无）  ──► │  BotConnection(空连接)     │ ──► FakePlayerObject ──► FakePlayerBrain
                 └──────────────────────────┘
```

好处：

| 能力 | 是否天然可用 |
|---|---|
| 客户端渲染（外观 / 装备外观 / 等级 / 头顶名字 / 行会 / 翅膀 / 光效） | 是，**客户端一行代码都不用改** |
| 走路 / 跑动 / 攻击 / 施法的动作与特效广播 | 是（`S.ObjectWalk`、`S.ObjectRun`、`S.ObjectAttack`、`S.ObjectMagic`…） |
| 头顶血条、受伤飘字、死亡倒地 | 是 |
| 普通说话 / 全屏喊话气泡 | 是 |
| 组队（邀请 / 入队 / 队伍列表 / 队员位置 / 一起下图） | 是（见 4.3：假人会答应邀请并跟随队长） |
| 交易 / 结婚 / 行会 / 攻城 | 是（框架全部复用，本版本没让假人去用） |
| 假人之间互相 PK | 是（见 4.2） |
| 被玩家攻击、被怪打、掉血、死亡 | 是 |

唯一需要「作弊」的两处，都写在明面上：

1. **`BotConnection`**：`MirConnection` 的派生类，构造时不建 socket，`Enqueue()` 直接丢弃
   所有下行包。这样 `HumanObject.Process()` / `PlayerObject.Process()` 里
   `if (Connection == null) return;` 的守卫能正常通过，逻辑跟真人完全一致，
   但没有人真的在收包。
2. **`FakePlayerObject`**：`PlayerObject` 的派生类，只做两件事：
   - `Process()` 末尾多跑一次 `Brain.Tick()`；
   - `Die()` 里记一个「几秒后自动复活」的时间戳。

## 三、配置

配置文件：**`Configs/Setup.ini`**（服务端运行目录下）。

```ini
[FakePlayer]
; 总开关
Enabled=True

; 生成多少个假人（0 表示不生成，上限 300）
Count=50

; 随机等级区间（含两端）
LevelMin=32
LevelMax=45

; 练级地图。写地图文件名或地图序号，逗号分隔，例如 0,1,2,3
; 留空则自动挑选「有怪物刷新点」的地图（按序号取前 20 张）
Maps=

; 假人会不会说话 / 喊话
Chat=True

; 假人会不会随机上下线（关掉的话就是 50 个假人一直在线）
RandomLogin=True

; 台词文件（相对 Configs 目录）
ChatFile=FakePlayerChat.txt

; 装备方案文件（相对 Configs 目录）
EquipFile=FakePlayerEquip.txt

; 假人之间会不会在野外随机 PK（互相切磋）
PK=True

; 每轮判定「要不要挑个人打」的概率（%）
PKChance=6

; 允许假人接受组队邀请，并跟随队长一起换图打怪
Follow=True

; 假人登录点（内联写法，多个点用分号隔开，格式 地图序号:X,Y）
; 一般不用写这里，直接编辑下面的登录点文件更方便
Spawns=

; 登录点文件（相对 Configs 目录）。文件里每行一个「地图 X Y」，
; 假人上线时就站在这些点上；留空或文件里没内容 = 在活动地图上随机登录
SpawnFile=FakePlayerSpawns.txt
```

### 3.1 各项说明

- **`Enabled`**：总开关。改成 `False` 后重启服务端就不会生成任何假人。
- **`Count`**：生成数量。50 个假人对服务端压力很小（见第六节）。
- **`LevelMin` / `LevelMax`**：假人等级随机区间。等级会影响：
  - 能穿什么装备（Manager 会按等级从物品库里挑「该等级该职业最强的一批」）；
  - 能学什么技能（按技能的 `Level1/2/3` 门槛自动给到对应熟练度）；
  - 单体血量、攻击力。
- **`Maps`**：建议留空让系统自动挑。留空时会自动选「主城 + 有怪物刷新点的地图」
  （日志里会打印实际挑了几张），因为主城也得纳入 —— 假人回城补给就在那儿站着。
  如果想让假人集中在某些图（比如都在新手村附近），
  写成 `Maps=0,1,2,3` 或者 `Maps=比奇省,沃玛森林`。地图文件名/标题都能识别。
- **`Chat`**：关掉的话假人就完全不说话了（安静但少点人味）。
- **`RandomLogin`**：开启时，每个假人在线 25~80 分钟后会下线，离线 2~12 分钟后再上，
  于是在线人数会在 40~50 之间自然波动。
- **`ChatFile`**：台词文件。文件里每行一句，以 `#`、`;`、`//` 开头的行会被当注释忽略。
  留空则使用代码里的内置台词库。
- **`EquipFile`**：装备方案文件（详见 3.3）。文件不存在时服务端会自动生成一份模板，
  里面预置了 6 套按本服物品库写的 30~45 级道具方案。
- **`PK`**：假人之间会不会在野外互相切磋（详见 4.2）。**默认打开**。
  只发生在「允许打架的地图 + 双方都不在安全区 + 双方都闲着」的时候，绝不主动打真人，
  也绝不打同队的队友。关掉就只有打怪了。
- **`PKChance`**：每次判定（约 30 秒~1.5 分钟一轮）「挑起一场切磋」的概率（%）。
  默认 6，也就是平均十几分钟才有一个假人发难，不会满屏乱斗。嫌少了就调到 15~25。
- **`Follow`**：允许假人接受组队邀请并跟随队长（详见 4.3）。**默认打开**。
  关掉的话假人仍然会进组，但不会跟着走，也不会因为队长阵亡而重登。
- **`SpawnFile`**：登录点文件（详见 3.4）。文件不存在时服务端会自动生成一份模板。
  留空 = 不读文件，走「在活动地图上随机找位置」的老逻辑。
- **`Spawns`**：登录点的**内联**写法，一行写完多个点，格式 `地图:X,Y; 地图:X,Y`，
  例如 `Spawns=0:330,330; 3:300,300`。**平时不用写这个**，直接编辑上面的文件更好维护。
  它和文件里的点会**合并**使用。

### 3.4 登录点（`Configs/FakePlayerSpawns.txt`）

**不配这个文件**时，假人是从「活动地图」里随机挑一张、再在图上随机找个点落下来。
好处是省事，坏处是你没法控制它们出现在哪 —— 想让它们集中在某几张图上就得费点劲。

配了登录点之后，**假人每次上线都会从你写的这些「地图 + 坐标」里随机挑一个落下**：

```
# 每行一个「地图 X Y」，# ; // 开头是注释
0 329 269
0 304 257
1 315 82
沃玛森林 320 90
3,330,330
```

- **地图**可以写地图序号（`0`）、地图文件名或地图标题（`沃玛森林`），不区分大小写；
- **分隔符**：空格、逗号、冒号都行（`0 330 330` / `0,330,330` / `0:330,330`）；
- **每次上线随机挑一个点**（包括随机上下线重登、死亡重登都是重新随机），
  50 个假人反复上下线后会自然铺开到各个点上；点数越少、每个点越挤；
- **复活点跟着这一次的登录点走**：假人死后回城复活会回到**这张图的安全区**，而不是回主城，
  所以它们不会一死就永远离开你指定的图；
- 配置的坐标**必须能站人**（不能是墙或地图外），否则那一行会被跳过并在控制台打一行提示；
- 配了登录点后还有一个连带效果（这是故意的）：
  **补给完也回这些图**：回城补给结束后，75% 的概率挑登录点所在的图继续练级。
- 改完不用重启服务端：游戏里用 GM 账号敲 **`@假人 reset`** 重新生成即可；
  想确认到底读进去了哪几个点，敲 **`@假人 登录点`**。

> 💡 坐标怎么找？进游戏站到你想让假人出现的位置，看服务端 GUI 的玩家信息，
> 或者直接照抄地图配置里的安全区坐标（`Exports/1_地图数据.txt` 里 `SAFEZONE(地图,范围,X,Y)` 那几行）。
> 模板文件里已经按本服 `Maps=0,1,2,3` 预填了飞天县 / 沃玛森林 / 毒蛇山谷 / 梦村县 共 13 个点，可直接用。

### 3.3 装备方案（`Configs/FakePlayerEquip.txt`）

想精确控制假人穿什么、几级，就写这个文件——**一个文件里可以写好几套方案，
假人上线时从「匹配自己职业」的方案里随机抽一套**，下线再上线就换一套：

```
[战士重装]
职业=战士
等级=40-45
武器=龙纹剑2
盔甲=黑龙战甲(男)60
头盔=钢铁头盔
项链=赤兰项链
手镯=魔鬼手镯
戒指=虎威戒指
腰带=黄金腰带
靴子=赤鳞靴
守护石=木青石(特)
```

规则：

- **`等级=最小-最大`**：假人等级在区间内随机；不写就用 `Setup.ini` 的全局等级；
- **`职业=战士 / 法师 / 道士 / 刺客 / 弓箭`**：可选；不写则所有职业都可能抽到这套；
- **部位名**：武器 盔甲(上衣) 头盔 项链 手镯 戒指 腰带 靴子 守护石 护身符 照明物；
  `手镯` / `戒指` 写一次自动穿双手 / 双只；
- **物品名必须与物品库完全一致**（含括号和数字后缀）；写错的部位会被跳过并打一行
  提示日志，然后由自动配装兜底补一件等级相称的；
- **盔甲分男女**：写 `(男)` 就行，遇到女性假人系统会自动换成 `(女)`；
- 服务端仍会校验职业 / 性别 / 等级需求，穿不上的自动换兜底装备；
- 方案没写的部位全部由自动配装补齐（按等级窗口挑最强的前 5 随机取 1）；
- 改完**重启服务端**生效。

### 3.2 改配置的注意事项

`Configs/Setup.ini` 由服务端的 `InIReader` 管理：它在启动时读一份**内存快照**，
之后每次 `Write()` 都会用快照**整文件重写**。

> ⚠ 所以改 `Setup.ini` 前请先**关掉服务端**，改完再启动；否则运行期手改的内容会被覆盖。

修改 `Configs/FakePlayerChat.txt` 不需要这样——它每次启动才读一次。

## 四、假人到底会做什么

`FakePlayerBrain` 是一个状态机，状态有：`Roam`（巡游找怪）、`Idle`（发呆）、
`Combat`（打怪 / 打架）、`Loot`（跑去捡东西）、`Restock`（回城补给）、`Dead`（躺尸）、
`Follow`（跟着组队的玩家跑）。

每一轮决策（400~700ms，带随机抖动）大致这样走：

0. **组队维护** → 有人邀请就**直接同意**；如果队里已经没有在线的真人玩家，就退组（见 4.3）；
1. **死了** → 躺 4~12 秒 → `TownRevive()` 回城复活 → 顺便当一次「回城补给」；
2. **在发呆** → 什么都不干，只维护吃药；
3. **自动喝药** → 血量低于 60%~80%、蓝量低于 35%~55% 时从背包里找最合适的药吃
   （缺血时绝不拿蓝药顶，血优先；同职业不符的药如「战士体力仙丹」会被跳过）；
   如果**背包里没药了**：先看地上有没有药（有就去捡，见下面第 3.5 条），
   地上也没有才按概率转成回城补给；
4. **在补给中** → 在驻地站着（8~20 秒，顺手回血回蓝）→ 补满药 → 挑一张活动地图 → 传送过去；
   （配了**登录点**的话，这里的「回城」回到的是登录点所在的图的**安全区**，而不是主城 ——
   这样假人才会一直在你指定的那几张图里活动）
3.5. **药快见底时的急救捡药** → 身上血药或蓝药少于 2 瓶时，专门扫一遍脚边的
   **药水**（血/蓝各见底时最多扫 6 格，否则 3 格），有就直接过去捡。
   这条特意排在「打架 / 捡东西」之前 —— 原来的捡物只在「手上没目标」时才做，
   而野外几乎永远有怪，结果假人一路打怪、一路把地上的药全错过；
5. **找怪** → 以自己为中心螺旋扫描 9 格内的怪物（只打野怪，不打别人的宝宝、
   不打弓箭手卫兵、不打玩家），找到就打；
6. **战斗** → 只要怪进了自己技能的射程就放技能（**贴脸也放**，不然怪一凑上来，
   法师道士就永远在抡拳头，技能等于白给）；技能用不了时才退化成肉搏：
   - 战士：正好 2 格且走的是直线 → **刺杀**（`Spell.Thrusting`）；贴脸就砍，
     身边怪多且学了半月/十方斩会甩出去（视觉上更丰富）；
   - 法师：射程内放 雷电 > 大火球 > 火球 > 冰咆哮；
   - 道士：射程内放 灵魂火符，自己血量低于 55% 时先给自己**治愈术**；
   - 弓箭手：射程内放 刺击（`StraightShot`）；
   - 刺客：贴脸用 双重砍击（`DoubleSlash`）。
   **打不到的怪绝不硬耗**：
   - 该走的位就走过去（刺杀要直线、近战要贴脸，够不到就挪到够得到的位置）；
   - 蓝不够时**不再原地狂丢技能**，直接凑近打 / 换目标；
   - 每 6 秒对账一次：怪一滴血都没掉（隔着墙、打不中、太硬）→ 立刻换目标；
   - 被**怪**攻击时 **70% 概率立刻还手**打它的怪；
   - 被真人**玩家**攻击时同样还击（走和真人一样的 PK 通道，安全区/新手保护照常生效。
     注意：**假人杀人不记 PK 点数**，所以假人永远不会红名 —— 否则 50 个假人打几轮
     就全红了，复活回城被卫兵追着射，直接变成死亡循环）；
   - 血量低于 30% 触发**躲避**：朝远离威胁的方向走位 2~4.5 秒（远程边撤边打），
     顺便给吃药留时间。
7. **没怪** → 找地上的掉落物（7 格内），走过去 `PickUp()`；
   **同一圈里优先捡药水和金币**，其次才是装备 —— 背包就那几格，见什么捡什么的话
   很快就塞满垃圾、真正要用的药反而捡不进来；
   捡完顺手检查背包，**有比身上更强的装备就换上**（一次只换一件，不会瞬间换一身）；
8. **巡游** → 随机挑一个 13 格内的可达点走过去；到了之后有 35% 概率原地发呆 2.5~16 秒；
9. **背包太满** → 越满查得越勤（空地少于 5 格时每 3 秒看一次，宽裕时 12~20 秒一次），
   最多一次丢 5 件杂物 / 用不上的装备。药水和护身符**永远不丢**。
   没药又背包满时会**立刻**腾位置，保证地上的药捡得进来；
10. **聊天** → 每 1~5 分钟说一句话，其中约 12% 是**全屏喊话**；打怪时不说话；
11. **换图** → 每 10~30 分钟「回城」一次（表现上就是用了张回城卷），补给完再挑新图。

### 4.1 一些刻意的细节

- **不会爆装**：假人死亡不掉装备（见第七节说明）。否则跑几个小时后，
  地图上会出现一堆光着身子乱跑的高等级怪人。
- **不会离出生点太远**：超过 16 格会自动往回走，避免假人跑到地图角落卡死。
- **开局先站一会儿**：刚上线时会有 3~20 秒的停顿，模仿「刚进游戏在读条」。
- **装备按等级相称来挑**：只在「等级需求落在我 Level-15 ~ Level 之间」的装备里选，
  这样既不会穿得寒酸，也**不会撞上 `孤鹜`、`落霞` 这类 Lv1 却属性爆表的 GM / 活动装**
  （那玩意儿一穿就一眼假）。窗口里实在没候选时才放宽成「等级够就能穿」。
- **装备参差不齐**：挑装备时从「同部位最强的 5 件」里随机选 1 件，
  并且有 12%~40% 的概率干脆空着某个部位，所以 50 个假人不会穿成一模一样。
- **技能是配出来的**：`LearnBasicSpells()` 按职业 + 等级把该会的技能全学会
  （`Spell` 枚举本来就是按职业分段排的，直接用数值区间判断归属，不用逐个点名，
  以后服务端技能表怎么改都不会漏），技能等级按人物等级推到 0~3 级，
  其中 30% 的假人故意差一级 —— 看起来就像真人在慢慢练。
  没有这一步，法师和道士就是两个抡拳头的普通人。
- **超负重开启**：假人身上带 `OverWeight = true`，否则按等级配的高级装备很容易
  超出「装备负重」，结果就是身上一件都穿不上。
- **不进排行榜**：`Envir.CheckRankUpdate()` 里直接排除假人，
  所以排行榜上只有真人；但**在线人数会算上假人**（`Envir.OnlineRankingCount`
  在假人上线 / 下线时同步加减）。

### 4.2 假人之间的随机 PK

野外闲逛的假人偶尔会找另一个假人切磋一下（`PK=True` 时开启，默认开）：

- **什么时候会打**：每 30 秒~1.5 分钟判一次，按 `PKChance`（默认 6%）的几率发难。
  平均下来十几分钟才有一场，不会满屏乱斗；
- **打谁**：只用螺旋扫描找 **9 格内另一个正闲着的假人**（还在打怪的不撩、已经组队的不撩、
  在安全区的不撩、和平地图（`NoFight`）不打），而且是**就近随缘**，不一定撩最近的那个；
- **对方会还手**：被打的假人会立刻转身反击（见 `OnAttacked`）；
- **打多久**：一场单挑最长 45 秒，到点双方自动收手各回各家（不然两个血厚的假人能在野外
  对砍到天荒地老，反而很怪）。分不出胜负也不算亏，观感就是「两个玩家打了一架」；
- **打不过会跑**：血量低于 30% 触发躲避走位；死亡照常回城复活；
- **死亡不掉装备**：假人死亡本来就不掉东西（见第七节），所以互相打不用担心装备流失；
- **不会红名**：假人杀人不记 PK 点数（`PlayerObject.Die()` 里排除），
  不然打几轮全员红名，复活回城就被卫兵追着射去了；
- **不会主动打真人**：找切磋对象时只认 `FakePlayerObject`。但真人**打了**假人是会被还手的
  （见上面第 6 条），而且群攻技能（半月弯刀之类）偶尔会蹭到旁边的真人 —— 这是原生
  PK 通道的行为，介意的把 `PK=False` 关掉即可。

### 4.3 组队与跟随

假人是真的 `PlayerObject`，所以它**天然就在服务端的组队系统里**，不需要任何额外改造。
要做的事情只有两件：让它会**答应**邀请，以及让它**跟着走**。

**怎么拉假人入队**

1. 在游戏里打开组队面板，输入假人名字点「邀请」（假人和真人一样，名字就在头上）；
2. 或者（推荐）走近几个假人，用 GM 命令 `@假人 组队 [数量]` 一次性拉身边最多 8 个
   （默认 3 个，范围 15 格）。

假人**永远会同意**邀请（不用等确认），入队后会打一行提示给你。

**入队之后它做什么**

- **跨图跟随**：队长换地图了，假人跟着「进图」（落到队长身边 3 格内的随机落脚点）；
- **贴身跟随**：同图时离队长超过 4 格就往前走，已经在旁边 2 格内就站着看戏；
- **跟得上人**：离队长超过 **13 格**就**放下手上正在打的怪/正在打的架**先追人
  （人都跟丢了，多打一只怪没有意义）；要是追上 16 格开外（队长飞了 / 路被地形堵死），
  直接落到队长旁边（3 秒冷却），宁可突兀也不跟丢；
- **一起打怪**：找怪的目标点从「自己身边」换成**队长身边**（优先打队长正在打的怪），
  但不会为了追一只怪跑离队长 12 格以外；
- **帮队长 PK**：队长动手打了哪个玩家，假人就上去打那个玩家；谁打了队长（或队伍里任何一个人），
  假人也会一起上 —— 这就是一队人围殴的效果。判定依据是服务端记录的两个原生信号：
  队长自己身上的「最近主动打了谁」（`HumanObject.RecentPvPTarget`，普攻和技能都会记），
  以及「谁最近打了我」（`LastHitter`，10 秒窗口）。跟着打架时不套用 45 秒的收手限制，
  只要队长还在打就继续帮；队长停手 12 秒后才散开；
- **不请假**：跟随期间不回城补给、不换图（不然就把人跟丢了）。
  如果在城里（安全区）待着，会顺手把药补满；
- **不会误伤队友**：入队后攻击模式切成 `Group`（打所有外人、绝不打队友），
  群攻也不会蹭到队友；退队自动切回 `All`；
- **不会随机掉线**：组队中的假人不参与「随机上下线」，所以不会跟到一半突然消失；
- **队长阵亡 → 自行下线重登**：队长（真人玩家）一死，假人立刻退出这趟行程 ——
  下线，然后在 4~15 秒后**自己重新上线**，恢复成没人管的自由假人。
  这样你复活回城时，身边不会留一串在地图深处发呆的跟班；
- **队长下线 → 自动退组**：队长掉线后假人会自己退组，不会在队伍列表里留一个幽灵队友
  （这点很重要：组队列表是全队共用的同一个 List，留着一个已经销毁的对象会连累别人）。

> 想让假人**不要再跟**了：直接用组队面板把它踢出队，或者你自己退队即可。
> 想彻底关掉这套行为：`Follow=False`。

## 六、性能

- 假人挂在 `Envir.Objects` 这条全局链表上（`Spawned()` 里挂的），
  主循环会按 `OperateTime` 逐帧驱动它们的 `Process()`。
- **假人是「降频驱动」的**：`FakePlayerObject.SetOperateTime()` 把间隔设成 **130~280ms 随机**
  （真人玩家这条是 `OperateTime = Envir.Time`，也就是主循环每扫一遍就处理一次）。
  这样做的两个理由：
  1. 假人身后没有客户端在等它的位置更新，晚 100~200ms 处理一次肉眼看不出来；
  2. AI 大脑本来就 380~700ms 才决策一次，处理频率再高也是空转。
  结果：50 个假人占的主循环时间只有「50 个真人玩家」的 1/5 左右，
  而且**随机错开落点**，不会 50 个一起在同一帧醒来顶出毛刺。
- AI 决策本身被单独卡到 **380~700ms 一次**，所以真正的「思考」开销可以忽略。
- 找怪 / 找地面物品是「螺旋扫描最近优先」，找到第一个就返回，
  最多 9 格（19×19 格），并且各自有 0.8~1.5 秒的间隔。
- 所有节拍都带随机抖动，50 个假人不会同时醒来，不会形成周期性的 CPU 尖峰。
- **广播不发给假人**：假人同样躺在 `Map.Players` 里，但身后的连接是 `BotConnection`，
  发给它的包会被直接丢掉。所以 `MapObject.Broadcast` / `Map.Broadcast` /
  `Map.BroadcastNPC` 里都直接把假人跳过 —— 不然地图上每条广播都要白扫 N 个假人。
- 假人**不写玩家日志**（`Reporting.LogMessage` 里直接跳过），
  也不写 `Server.MirDB`（它们不在 `Envir.CharacterList` / `Envir.AccountList` 里）。
- 假人**会**写聊天日志（`Configs/../Logs` 里的 Chat 日志），因为它们确实在聊天。
  介意的话把 `Chat=False` 关掉即可。
- 下线时控制台会打一行「XXX 已退出游戏 原因: 返回人物选择界面」——
  这是 `StopGame()` 自带的日志，**没有**被屏蔽，因为它让假人看起来就像真的玩家在上下线。
  介意的话可以按需要屏蔽（`PlayerObject.StopGame()` 里那句 `MessageQueue.Enqueue(logReason)`）。

### 6.1 客户端跑起来卡顿，是不是假人拖的？—— 用 `@假人 性能` 一句话判断

假人确实会占服务端资源（≈ 几十个真人玩家的量级），但**通常不是客户端跑动卡顿的原因**。
判断方法（GM 账号在游戏里）：

```
@假人 性能
```

会回一行这样的东西：

```
[假人性能] 主循环周期：当前 8ms，峰值 23ms；世界对象 5421 个（在线玩家 53，其中假人 50）；
假人 Process：每秒 268 次，合计 4.1ms（约 0.41% CPU）；大脑 Tick：每秒 132 次，合计 0.7ms；
因收件人是假人而跳过的广播：每秒 1842 次
```

怎么读：

| 看到的现象 | 结论 |
|---|---|
| 「假人 Process」合计只有**个位数 ms**（约 0.0x% CPU） | **跟假人无关**，别再从假人身上找原因 |
| 「主循环周期」当前/峰值都在 **30ms 以内** | 服务端很闲，卡顿在客户端或网络 |
| 「主循环周期」当前就 **100ms+**，峰值几百 ms | 服务端自己在卡，客户端自然跟着一顿一顿 |
| 「世界对象」异常大（几万以上） | 有怪物/掉落物堆积，才是真凶 |

> 「主循环周期」就是服务端界面右下角那个「延迟周期」（`Envir.LastRunTime`）：
> 它是一整轮扫完 `Envir.Objects` 花掉的时间。这个值一大，玩家发出来的
> 走/跑/攻击包就要排队等下一轮才被处理，客户端表现就是**跑一步顿一下、偶尔回拉**。

**客户端卡顿的常见真凶**（按概率排）：

1. **微端边跑边下资源**（最像「跑动过程中卡顿」）：
   走进没去过的区域，客户端缺贴图/地图块，边跑边从服务端 HTTP 拉几十 MB 的 `.Lib`。
   特征：**只在第一次经过的地方卡**，同一条路再走一遍就顺了。
   可以在服务端控制台把 `ResourceVerboseLog` 打开，看是不是卡的同时正好在下资源。
2. **同屏对象太多**：带着一串假人 + 一群怪同屏，老客户端单线程渲染直接掉帧（和假人数量正相关，
   但换一台显卡好的机器或换个少怪的地图就不卡了，就能区分开）。
3. **网络抖动/丢包**：特征是别的玩家瞬移、自己偶尔被拉回原位，且和服务端延迟周期无关。
4. **服务端主循环拥塞**：看上面那张表。
5. **客户端本机问题**：机械硬盘随机读、杀软实时扫描、DirectDraw/D3D 兼容、中文系统下的输入法。

**A/B 对比最干脆**：先在 `Setup.ini` 里把 `Enabled=False` 重启服务端（一个假人都没有），
按同一条路线跑一遍；再 `Enabled=True` 跑同一条路。两次都卡 → 与假人无关。

## 七、这套实现「不做什么」与已知边界

- **不主动 PK 真人**：单打独斗的假人只对打它的玩家还手；找切磋对象时只认别的假人。
  **例外**：被玩家拉进队、跟着玩家走的假人会**帮队长打**（见 4.3）——
  队长打了谁、谁打了队长，它们就一起上。想安静就把 `Follow=False` 关掉。
  另外**假人之间会随机互殴**（见 4.2），关掉就安静了。
- **不爆装**：假人死亡不掉装备（`DeathDrop` / `RedDeathDrop` 里排除）。
  所以 PK 假人爆不出东西，别拿假人当装备来源。
- **查看假人**：管理界面双击假人看信息、游戏里 Ctrl+点击假人看装备，都已支持
  （假人不在持久化角色表里，相关查询做了在线兜底）。

为了避免影响真人的游戏体验，下面这些事情刻意没做，或者干脆禁掉了：

| 项目 | 说明 |
|---|---|
| 假人打真人 | 单独行动的假人**只还手不先动手**：被玩家攻击时按真实 PK 规则还击；不打别人的宝宝 |
| 跟队的假人打真人 | **会**：只在「队长先打了那个人」或「那个人打了队长/队友」时才上（`Follow=True` 时启用），是帮架不是乱咬 |
| 假人之间的 PK | 会（`PK=True` 时）：只在允许打架的野外、双方都闲着时发生，单场最长 45 秒 |
| 假人爆装 / 掉落 | `HumanObject.DeathDrop()` 与 `RedDeathDrop()` 里直接跳过假人，死亡不掉东西 |
| 假人进排行榜 | `Envir.CheckRankUpdate()` 里排除，榜上只有真人 |
| 假人行会 / 攻城 / 组队排名 | 假人没有行会（`GuildIndex = -1`），不会参与任何排名 |
| 假人存档 | 全部只存内存，重启即重新生成（等级、装备都会重新随机） |
| 假人交易 / 摆摊 / 邮件 | 没实现，假人不会给任何人发东西 |
| 假人做出真实 NPC 购买 | 补给是「走到安全区 + 站定一段时间 + 把药补满」，没有真的调用 NPC 买卖协议 |

> 「补给」这一条是唯一明显的近似：假人回城后会直接用服务端的 `Teleport()` 传送，
> 旁观的真人看到的是**传送特效**（跟玩家用回城卷一模一样），
> 不会看到假人在城里走来走去逛商店。

## 八、验证步骤

1. 确认服务端**没有在运行**（`Server.exe` 进程不存在）；
2. 把 `Server/bin/Release/Server.Library.dll`（和 `.pdb`）覆盖到服务端运行目录；
3. 确认 `Configs/Setup.ini` 里有 `[FakePlayer]` 段，且 `Enabled=True`；
4. 确认 `Configs/FakePlayerChat.txt` 存在；
   想固定假人的出生位置，确认 `Configs/FakePlayerSpawns.txt` 里写了「地图 X Y」；
5. 启动服务端，控制台应该出现
   `[假人] 已加载登录点 N 个，分布在 M 张地图上`（没配的话是 `未配置登录点，按活动地图随机登录`）、
   `[假人] 自动挑选活动地图 N 张（主城 X 张 + 有怪物刷新的图 Y 张）`
   和 `[假人] 已生成 50/50 个假人，活动地图 N 张，在线 50 人`；
   如果有 `登录点里的地图找不到` / `登录点站不住` 这类提示，就是那一行配置写错了；
6. 用客户端登录，先站在主城里看看 —— 应该能看到有假人在走动、偶尔说一句话；
   再去一张练级图，能看见假人打怪；
   **配了登录点时**，进 `@假人 登录点` 里列出的那几张图，就应该在对应坐标附近看到假人
   （上线时他们会先站 3~20 秒「读条」，别急着走开）；
7. **重点看一眼法师 / 道士**：他们应该在放雷电、灵魂火符，道士血低了会给自己治愈术，
   而不是全员贴上去抡拳头。如果是抡拳头，说明服务端技能表里没有对应技能
   （`LearnBasicSpells` 会静默跳过查不到的技能，不会报错）。
8. 管理员账号登录后输入 `@假人` 看状态，`@假人 药` 看在线假人的血量和背包药水，
   `@假人 登录点` 看登录点有没有读对。
9. **测组队跟随时**：出城找几个假人，`@假人 组队` 把它们拉进队 →回城/换图 →
   它们应该跟着你落到同一张图并开始打你身边的怪；你死了它们应该立刻消失（下线），
   十几秒后再在别处冒出来（重登）。
   - **测追上**：组好队后开着人物往一个方向猛跑，假人应该一路跟着跑；
     跑出 16 格以上（比如你用随机传送 / 走传送点）它们会直接落到你旁边，不会走丢。
   - **测帮打架**：带着假人去找另一个假人（或另一个测试号），你先动手打它 ——
     跟队的假人应该马上一起上；反过来，如果对方先打你，它们同样会一起上。
     注意：只有**开了打架的地图**（非安全区、非 `NoFight`）才行。
10. **测互殴**：去一张允许打架的野外地图待一会儿（`PKChance=6` 时平均十几分钟一场），
    能看到两个假人互相砍；把 `PK=False` 关掉应该就再也看不到。
11. **测捡药 / 吃药**：跟着一个假人打一会儿怪 —— 地上爆出的药水它应该会去捡
    （同一距离下优先捡药和金币）；血掉到 80% 以下就会自己灌药。
    敲 `@假人 药` 能看到抽样假人的血量百分比和血药/蓝药瓶数。
    想看得更明显就把某个假人打成重伤，它要么喝药、要么跑去捡地上的药。
12. 有假人相关的报错，控制台会打 `[假人AI] 名字 出错：...`（一个假人只报一次，不会刷屏）。

如果第 5 步没出现那行日志，看控制台有没有
`[假人] 找不到可用的活动地图` —— 那就说明该服务端的地图数据里没有任何怪物刷新点，
此时需要在 `Setup.ini` 里手动指定 `Maps=`。

## 九、后续可以加的东西

- 假人摆摊 / 开店（复用 `GameshopList`）；
- 假人加入行会，参与行会聊天（`ChatType.Guild`）；
- 假人之间有概率互相搭话（A 说完 B 接一句）；
- 假人跟着喊话内容去某个地图（"打祖玛的组队" → 真的跑去祖玛）；
- 按地图配置不同的假人数量（新手村 10 个，祖玛 5 个…）；
- 法师 / 弓箭被怪贴身时**后撤放风筝**（现在是在原地顶着打，够用但不够"聪明"）；
- 道士召唤骷髅（`Spell.SummonSkeleton`）当肉盾；
- 组队时假人会主动给队长加血（道士）/ 会自己开组邀请附近的真人和假人；
- 组队时假人分队包抄、集火同一个目标。
