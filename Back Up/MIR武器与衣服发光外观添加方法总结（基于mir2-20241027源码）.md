# MIR 武器 / 衣服发光外观添加方法总结

> **基于源码**：`D:\mir2-20241027`（C# 版 Legend of Mir 2，Client / Server / Shared 结构）
> 整理日期：2026-10-24

---

## 一、核心结论

本源码中装备发光**不使用 `SETITEMEFFECT` 之类 NPC 脚本命令**（全仓库无此命令），而是走一条固定链路：

```
ItemInfo.Effect 字段（M2 表单配置，存入 Items.db）
        │  玩家穿戴装备
        ▼
HumanObject.RefreshEquipmentStats()
        │  武器 → Looks_WeaponEffect = Effect
        │  盔甲 → Looks_Wings = Effect（盔甲特效复用"翅膀"通道）
        ▼
封包 S.ObjectPlayer / S.PlayerUpdate（WeaponEffect / WingEffect / Light）
        ▼
客户端 PlayerObject.SetLibraries() 索引特效图库
        ▼
DrawWeapon() / DrawWings() 用 DrawBlend 与本体同帧叠加 → 发光
```

一句话：**武器和衣服的发光编号都来自物品模板的 `Effect` 字段（byte，0~255），配置在 M2 的物品表单里，客户端按编号加载特效图库半透明叠加。**

---

## 二、字段定义（Shared/Data/ItemData.cs）

| 字段 | 类型 | 作用 |
|---|---|---|
| `Effect` | byte | **特效编号**。武器 = 武器发光图库索引；盔甲 = 翅膀特效索引（1~99 有效） |
| `Shape` | short | 外观编号，决定用哪个本体图库 |
| `Light` | byte | 光圈亮度（0-255），人物周围光照，取全装备最亮值 |

- 定义位置：`Shared\Data\ItemData.cs` 第 14-15 行（Shape/Light）、第 23 行（Effect）。
- `UserItem`（装备实例）**没有**自己的 Effect 字段，特效始终取自其模板 `Info.Effect` —— 即同一种装备的所有个体发光一致。
- 二进制存取：`ItemInfo(BinaryReader)` 第 130 行 `Effect = reader.ReadByte();`，`Save()` 第 208/232 行对称写入。物品库为二进制 `Items.db`（`Server\MirEnvir\Envir.cs` 第 1374-1431 行 LoadDB）。

## 三、配置入口：M2 物品表单

修改 `Effect` 只有两个途径：

1. **旧版表单**：`Server.MirForms\Database\ItemInfoForm.cs`
   - 第 258 行加载：`EffectTextBox.Text = info.Effect.ToString();`
   - 第 1053-1070 行保存：byte 校验，非法值标红。
2. **新版表格**：`Server.MirForms\Database\ItemInfoFormNew.cs`
   - 列标题就叫"**特效**"（Designer.cs 第 207-211 行），位于 ItemShape 列之后。
3. 表单关闭时 `Envir.SaveDB()` 写盘（ItemInfoForm.cs 第 1072-1075 行）。**改完必须重启 M2**（或重载物品库）才生效。

> 与装备发光相关的运行时 GM 命令只有 `SETLIGHT <0-255>`（`Server\MirObjects\PlayerObject.cs` 第 4386-4395 行），只改人物光圈亮度，不改特效图。
> NPC 脚本中只有 `REFRESHEFFECTS`（NPCSegment.cs 第 1074 行），它刷新的是等级特效 LevelEffects，与装备发光无关。

## 四、服务端逻辑（Server/MirObjects/HumanObject.cs）

### 1. 状态字段（第 171 行）

```csharp
public short Looks_Armour = 0, Looks_Weapon = -1, Looks_WeaponEffect = 0;
// 另有 Looks_Wings
```

### 2. 穿戴刷新 RefreshEquipmentStats()

- 第 1994-2005 行：刷新前先清零 `Looks_WeaponEffect = 0`。
- 第 2037-2047 行（核心）：

```csharp
if (realItem.Type == ItemType.盔甲)
{
    Looks_Armour = realItem.Shape;
    Looks_Wings = realItem.Effect;        // 盔甲特效 → 翅膀通道
}
if (realItem.Type == ItemType.武器)
{
    Looks_Weapon = realItem.Shape;
    Looks_WeaponEffect = realItem.Effect; // 武器特效
}
```

- 第 2079 行：`if (realItem.Light > Light) Light = realItem.Light;`（光圈取全装备最亮）。

### 3. 下发封包

- 外观变化 → `UpdateLooks()` → `Broadcast(GetUpdateInfo())`（第 8654-8657 行）。
- `GetUpdateInfo()`（第 8639-8652 行）构造 `S.PlayerUpdate { Weapon, WeaponEffect, Armour, WingEffect, Light ... }`。
- 新对象进入视野 → `S.ObjectPlayer`（`PlayerObject.GetInfo`，第 4987-5007 行）同样携带这些字段。
- 封包定义：`Shared\ServerPackets.cs` —— `ObjectPlayer` 第 825-945 行（WeaponEffect 第 844 行）、`PlayerUpdate` 第 1681-1720 行。

## 五、客户端渲染（Client/MirObjects/PlayerObject.cs）

### 1. 接收

- 第 30-31 行：成员 `WeaponLibrary1, WeaponEffectLibrary1, ... ; Armour, Weapon, WeaponEffect, ...`
- `Load(S.ObjectPlayer)` 第 186/231 行存下 `WeaponEffect` 后调 `SetLibraries()`。

### 2. 图库索引 SetLibraries()（按职业/状态分派）

| 场景 | 逻辑 | 位置 |
|---|---|---|
| 法/战/道武器 | `WeaponEffect > 0` 时取 `Libraries.CWeaponEffect[WeaponEffect]` | 第 676-693 行 |
| 刺客武器 | Effect 须在 **100-199**，用 `Effect - 100` 索引 `AWeaponEffectL/R` | 第 612-616 行 |
| 骑马武器 | 取 `ARWeaponsEffect / ARWeaponsEffectS` | 第 504-516 行 |
| 盔甲（翅膀） | `WingEffect ∈ (0,100)` 时取 `CHumEffect[WingEffect - 1]` | 第 542-550 行 |

### 3. 绘制（DrawBlend 半透明叠加）

- `DrawWeapon()` 第 5903-5918 行：

```csharp
WeaponLibrary1.Draw(DrawFrame + WeaponOffSet, DrawLocation, DrawColour, true);
if (WeaponEffectLibrary1 != null)
    WeaponEffectLibrary1.DrawBlend(DrawFrame + WeaponOffSet, DrawLocation, DrawColour, true, 0.4F);
```

- `DrawWeapon2()` 第 5919-5934 行：左手/骑乘第二把，同理。
- `DrawWings()` 第 5935-5941 行：`WingLibrary.DrawBlend(...)` —— **盔甲发光的最终绘制**。
- 特效图与本体**帧号一一对应**（同 `DrawFrame`），所以发光会随人物动作同步播放。
- 角色预览面板：`Client\MirScenes\Dialogs\CharacterDialog.cs` 第 100-320 行，对 `WeaponEffect` 21/22/23/26~119 逐个映射 `Libraries.StateitemEffect` 图库叠加静态特效（装备栏图标发光）。

### 4. 特效图库文件与路径（Client/Settings.cs 第 42-61 行）

| 路径 | 用途 |
|---|---|
| `.\Data\CWeaponEffect\` | 法战道武器特效 |
| `.\Data\AWeaponEffect\` | 刺客武器特效（" L"/" R" 左右手两套） |
| `.\Data\ARWeaponEffect\` | 骑乘武器特效（另有 " S" 慢速版） |
| CHumEffect / AHumEffect / ARHumEffectPath | 盔甲翅膀特效 |
| `StateitemEffect` | 角色面板装备图标特效（MLibrary.cs 第 22 行） |

图库初始化：`Client\MirGraphics\MLibrary.cs` 第 271-304 行。特效素材是 `.Data\` 下的 MLibrary 图库文件，**编号即图库文件序号**（如 CWeaponEffect 编号 21 = 目录下第 21 套特效图库），由微端清单（`Tools\verify_micro_package.py` 第 20-50 行）分发。

## 六、实操步骤：给一件武器/衣服添加发光外观

### 给武器加发光（例：编号 21 的特效）

1. 准备特效图库：把序列帧特效（与武器帧号一一对应的整套动画）制作成 MLibrary 图库，放入客户端 `Data\CWeaponEffect\`（刺客则用 `AWeaponEffect` 且编号 +100）。
2. 启动 M2 → 物品信息表单（ItemInfoForm / New）→ 找到目标武器 → **特效**列填 `21`。
3. 关闭表单自动 SaveDB → **重启 M2**。
4. 客户端进游戏穿戴，武器即随动作同步发光；角色面板图标发光由 `StateitemEffect` 图库对应编号提供。

### 给盔甲（衣服）加发光/翅膀特效

1. 制作翅膀/流光图库放入 `Data\CHumEffect\`（编号从 1 开始）。
2. M2 物品表单中把该盔甲的 **特效** 填为对应编号（1~99）。
3. 重启 M2，穿戴后 `DrawWings()` 叠加显示。

### 想要人物光圈

把装备的 `Light` 字段填 0-255（多件装备取最大值），或运行时 GM 命令 `SETLIGHT <值>`。

### 想给"单个装备个体"不同发光

现有架构不支持（Effect 是模板字段）。若要实现，需要：给 `UserItem` 增加 Effect 字段并序列化 → `RefreshEquipmentStats` 里优先取 `realItem.Effect`（实例值，缺省回退 `Info.Effect`）→ 封包字段不变即可。

## 七、常见问题

| 现象 | 原因/排查 |
|---|---|
| 填了 Effect 不发光 | ① 客户端对应图库文件缺失或编号超界（如 CWeaponEffect 只有 20 套却填 21，`SetLibraries` 里直接判 null 不画）；② M2 未重启/未 SaveDB；③ 刺客武器编号没加 100 |
| 发光不同步/错帧 | 特效图库帧数与本体武器帧数不一致（两者按同帧号叠加） |
| 盔甲特效不显示 | 编号必须 1~99（`WingEffect < 100` 才索引 CHumEffect）；特效填在盔甲类型的物品上 |
| 图标栏不发光 | 需 `StateitemEffect` 图库有对应编号，且 CharacterDialog 中有该编号的映射分支 |
| 改动不生效 | ItemInfo 是二进制 Items.db，旧客户端缓存 / 微端未重新分发 Data 目录 |
