;=====================================================================
; 武器强化师 —— NPC 脚本
;---------------------------------------------------------------------
; 服务端：韩版 Mir2 / Crystal  ·  源码 D:\mir2-20241027
;
; 本脚本本身不含任何强化逻辑，只负责把服务端**原生**的两套强化系统
; 开放给玩家。真正的逻辑全在服务端代码里：
;   武器精炼  PlayerObject.RefineItem() / CollectRefine() / CheckRefine()
;             数值配置 Configs\RefineSystem.ini
;   装备觉醒  PlayerObject.AwakeningItem() 及相关方法
;             数值配置 Configs\AwakeningSystem.ini
;
; ★★ 下面四个页面名是服务端代码里写死的「保留页名」，一个字都不能改：
;     [@REFINE]         打开精炼面板
;     [@REFINECHECK]    打开精炼检查面板
;     [@REFINECOLLECT]  取回精炼完成的武器
;     [@AWAKENING]      打开装备觉醒面板
;   这四页里**不要写 #IF / #ACT**，引擎在进入页面时会自动把对应面板推给
;   客户端；页面里的 #SAY 会照常显示成对话框文字。
;
; ★ 重要限制：精炼与觉醒都要求玩家**站在本 NPC 旁边**（服务端会校验距离，
;   超过数据范围直接失败）。所以必须把本文件挂到数据库里真实存在的 NPC
;   记录上 —— 光把 .txt 丢进 Envir\NPCs\ 是不会生效的。
;
; 挂载步骤（三选一）：
;   1) 本文件放到 Envir\NPCs\武器强化师.txt
;      用 GM 工具（Server.MirForms）→ 数据库 → NPC → 新增，
;      FileName 填「武器强化师」（相对 Envir\NPCs\，可不带 .txt），
;      再填地图 / 坐标 / 外观（Image）。
;   2) GM 工具的 NPC 界面有「导入」按钮，可直接导入下面这一行数据。
;      格式：FileName,地图文件名,X,Y,显示名,外观,费率,大地图显示,大地图图标,
;            可传送,攻城可见,最小等级,最大等级,限时显示,起始时,起始分,结束时,结束分
;      武器强化师,0,330,330,武器强化师,50,100,False,0,True,True,0,0,False,0,0,0,1
;      （上面这行是示例：地图 0 = 比奇省，坐标 330,330，外观编号 50 —— 自行调整）
;   3) 改完脚本后游戏里输入 @RELOADNPCS 立即生效，不用重启服务端。
;
; 编码：UTF-8（带不带 BOM 都行，不要存成 GBK）
;=====================================================================


[@Main]
#SAY
武器要变强，找我准没错。\
手上的家伙想加攻击就精炼，身上装备想加属性就觉醒，两样我都做。\
 \
<武器精炼/@REFINE> <取回精炼武器/@REFINECOLLECT> <检查精炼结果/@REFINECHECK>\
<装备觉醒/@AWAKENING> <强化说明/@说明> <离开/@exit>


;---------------------------------------------------------------------
; 【保留页】武器精炼 —— 名字不能改
; 进页后服务端会推 S.NPCRefine，客户端弹出精炼面板：
;   · 放 1 件武器 + 首饰（可选）+ 黑色铁矿石（可选）
;   · 点「精炼」开始，扣金币，武器进入倒计时
;---------------------------------------------------------------------
[@REFINE]
#SAY
把要精炼的武器放进精炼槽，再搭些首饰和黑色铁矿石。\
首饰决定加哪种攻击，矿石和首饰越足、越纯，成功率越高。\
成功后可以额外加攻击，失败的话武器就直接碎了，想清楚再点。\
<返回/@Main>


;---------------------------------------------------------------------
; 【保留页】取回精炼完成的武器 —— 名字不能改
; 服务端 CollectRefine()：没到时间 / 背包满都会拒绝并给出提示
;---------------------------------------------------------------------
[@REFINECOLLECT]
#SAY
精炼要炼满时间才能取回，没到点我也变不出东西来。\
记得先把背包腾一格出来。\
<返回/@Main>


;---------------------------------------------------------------------
; 【保留页】检查精炼结果 —— 名字不能改
; 服务端 CheckRefine()：这里才真正掷成功率
;   掷不过 → 武器破碎；掷过 → 加攻击；另有 10% 几率暴击翻倍
;---------------------------------------------------------------------
[@REFINECHECK]
#SAY
精炼结果就在这里看。\
骰子一掷，成了加攻击，不成就碎了，没有回头路。\
<返回/@Main>


;---------------------------------------------------------------------
; 【保留页】装备觉醒 —— 名字不能改
; 进页后服务端会推 S.NPCAwakening，客户端弹出觉醒面板：
;   · 放装备 + 对应「雕文」+「觉醒之魂」，选要加哪种属性
;---------------------------------------------------------------------
[@AWAKENING]
#SAY
装备放进觉醒槽，配齐雕文和觉醒之魂，我就能给它加属性。\
细活慢工，最多能觉醒 5 级，材料按当前等级往上加。\
<返回/@Main>


;---------------------------------------------------------------------
; 普通说明页（非保留页，名字随意）
;---------------------------------------------------------------------
[@说明]
#SAY
【武器精炼】\
只对武器有效。需要武器 + 首饰 + 黑色铁矿石，都要放进精炼槽。\
首饰决定加哪种攻击：物理、魔法、道术，看哪样总和最高。\
金币消耗 = 武器等级要求 × 1250。\
精炼耗时 20 分钟，基础成功率 20%，首饰、矿石、幸运都能往上加。\
另有 10% 几率暴击，加成翻倍。\
★ 失败武器会直接破碎，贵重武器请谨慎。\
 \
【装备觉醒】\
装备 + 对应雕文 + 觉醒之魂，最高 5 级，能加这些属性：\
物理攻击（攻击雕文）、魔法攻击（魔法雕文）、道术攻击（道术雕文）、\
物理防御（防御雕文）、魔法防御（魔御雕文）、生命法力值（体力雕文）。\
每一级需要的材料 = 1 + 当前觉醒等级，等级越高越费料。\
雕文和觉醒之魂都按装备品级选：普通拿 0 号、宝物 1 号、圣物 2 号、神物 3 号。\
每级加多少看装备部位：武器 +1、头盔 +1、盔甲 +5。\
不是所有装备都能觉醒，放进去能不能炼，面板上会告诉你。\
 \
以上数值都写在 Configs\RefineSystem.ini 和 Configs\AwakeningSystem.ini 里。\
<返回/@Main>
