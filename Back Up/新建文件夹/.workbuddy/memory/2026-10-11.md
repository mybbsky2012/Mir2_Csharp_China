## 12:13-12:20 内挂「穿人」能穿城门 —— 已修（穿人不再穿城门/城墙）

### 问题

### 根因（★重要机制）
城门是**怪物对象**：`Gate : CastleGate : MonsterObject`，Race = `ObjectType.Monster`；
城门关闭时显形的那 8 个阻挡位是 `BlockingObject : MonsterObject`（`Blocking => Parent.Blocking`）。
而穿人白名单里 `ob.Race == ObjectType.Monster` 一刀切忽略 → 城门/城墙一起被放行。
涉及两处：服务端 `HumanObject.Walk` / `HumanObject.Run`（字符串 `WalkThrough &&`），客户端 `GameScene.EmptyCell()`。

- 客户端 `Client/MirObjects/MonsterObject.cs`：新增字段 + `Load` 里 `NoWalkThrough = info.NoWalkThrough`

## 15:30-16:00 ★★ `CHECKEXACTMON` 检测恒失败的真正根因（服务端 Bug，**已还原、未部署**）

1. `Server/MirDatabase/MonsterInfo.cs:138` →
   `public string GameName { get { return Regex.Replace(Name, @"[\d-]", string.Empty); } }`
