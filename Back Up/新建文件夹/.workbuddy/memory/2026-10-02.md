## 修复：毒符互换「一用技能就来回互切」（根因 = 优先级漏洞）
- 用户反馈：「毒符互换的功能是，使用需要符的技能就换成符，使用毒的技能就换毒，不是一用技能就来回互相切换」。
- **根因**：`AutoPlayWantPoison()` 在「槽里正好是目标还缺的那种毒」时 `return false`，流程于是落到第②支 `AutoPlayWantAmulet()`——而它有可打目标就返回 true（灵魂火符主攻要符）→ 同一帧/下一帧立刻换回符；下一帧又判定要施毒术 → 换毒……两帧之间符/毒无限互切。旧代码里 `GameScene.Scene.ChatDialog.ReceiveChat("内挂换毒/换符")` 就是刷屏的征兆。
- **修法（Client/MirScenes/GameScene.cs）**：
  1. `AutoPlayWantPoison` 改成「需要毒就返回 true」，槽里已是所需那种毒时也返回 true（shape=槽里那种），表示「粘住」；调用方看到 `equipped == wantPoison` 直接 `return false`（什么都不做，等施毒术放出去）。
  2. 第②支换符的门槛从 `AutoPlayHasItem(护身符,0,1)` 换成 `AutoPlayHasAmulet()`（同义，语义更清楚），且只有①整支返回 false 才会走到②。
  3. ①改为「换毒成功才 return true」：`if (load != 0 && equipped != load && AutoPlayEquipConsumable(load)) {...return true;}`；若背包里一个能用的毒都没有，**不 return false 卡住**，而是继续落到②按符纸技能处理（否则会一直空着毒槽、灵魂火符也放不出）。
  4. 目标解析：`MapObject.TargetObject` 不可用时，开了 `Settings.AutoAttack` 才回退 `AutoPlayFindMonster()`，与战斗同一套索敌。
  5. 加 `if (User.NextMagic != null) return false;`（正在施法不抢）。
  6. 删掉两处换装聊天提示（刷屏，槽里变化直接可见）。
- 编译：客户端 Release 0 错误 10 旧警告。文档 2.13 节重写（加「粘性判定/优先级/不空转」说明）。

## 毒符互换：支持「勾选即生效」（不必开内挂总开关）+ 手动施法按需换装
- 需求：「毒符互换勾选后直接就能用 不用非得开启自动模式」「就是勾选后我操作技能就能生效」。
- 关键结构补充：`Client/MirScenes/GameScene.cs` 里 GameScene 有实例字段 `public MapControl MapControl;`（所以 GameScene 内 `MapControl.Xxx(...)` 是**实例**访问，C# Color Color 规则）；手动施法的唯一入口是 `GameScene.UseSpell(int key)`（技能栏点击 `UseSpell(j+8*BarIndex)`，j=i+1 → Key 1..16，**0 可当"无"哨兵**；快捷键 KeybindOptions.Bar1Skill1..8 / Bar2Skill1..8），其 `default:` 分支设 `actor.NextMagic = magic`，再由 `MapControl.CheckInput` → `MapControl.UseMagic` 发包。Hero 用 key>16。
- 实现（MapControl，新区块「毒符互换（手动施法按需换装，不依赖内挂总开关）」）：
  * `AutoPlaySpellMaterial(Spell)`：3=任意毒（施毒术）；0=符（灵魂火符/隐身/集体隐身/幽灵盾/神圣战甲术/困魔咒/诅咒术/强化术/幻影术/回生术/阴阳五行阵-秘籍/召唤骷髅·神兽·月灵）；-1=不动（毒雾、瘟疫术要符+毒同时消耗，一槽满足不了）。
  * `AutoPlayEquippedMaterial()`：槽里是符(0)/绿毒(1)/红毒(2)/空(-1)。
  * `public bool AutoPlayPrepareManualSpell(ClientMagic magic)`：按技能决定要装什么；施毒术先问 `AutoPlayWantPoison` 目标缺哪种（否则按 `_autoPoisonNextShape` 交替）；想用的毒背包没有就用另一种；材料已就位→返回 false 照常施放；需换装→发包 + 记 `_manualSpellKey/_manualSpellWant/_manualSpellTime/_manualSpellUntil`(3s) + `_autoManualHoldUntil`(3s 静默期，期间 `AutoPlaySwapPoisonAmulet` 直接 return false)。
  * `AutoPlayRetryManualSpell()`：材料真到位（`AutoPlayEquippedMaterial()==_manualSpellWant`，且距发包 ≥120ms）就 `GameScene.Scene.UseSpell(key)` 补放；在 `MapControl.Process()` 里 `ProcessAutoPlay()` 与 `CheckInput()` 之间调用（不受总开关影响）。
  * 连按同一技能键时若已有同材料的待补放请求 → 返回 true 继续等，避免抢着放白耗蓝。
- 挂点：`GameScene.UseSpell` 的 `default:` 分支最前 `if (actor == User && MapControl != null && MapControl.AutoPlayPrepareManualSpell(magic)) return;`（只对 User，Hero 不变）。
- 面板提示语改为「毒符互换已开启：用吃符的技能自动换符、用吃毒的技能自动换毒（不必开内挂总开关）」。客户端 Release 编译 0 错误 10 旧警告，`Build/Client/Release/Client.exe` 已更新；文档 2.13 拆成 ①手动按技能换装 / ②自动挂机按目标换装 两节。
