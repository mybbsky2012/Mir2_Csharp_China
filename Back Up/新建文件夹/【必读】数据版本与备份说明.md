## 六、经验条显示异常（2026-09-28 修复）

### 现象

主界面底部的**经验条蓝色进度条长度固定不变**（恒定满格，不随经验增长而伸长）。

### 根因：`MaxExperience = 0` 引发的除零

`Configs/ExpList.ini` 只配置到 **Level500**，而服务端是这么取上限的：

```csharp
// Server/MirObjects/HumanObject.cs:1786
MaxExperience = Level < Settings.ExperienceList.Count ? Settings.ExperienceList[Level - 1] : 0;
```

**等级 ≥ 500 时 `MaxExperience` 变成 `0`**，于是：

1. **客户端**：`Experience / (double)MaxExperience`
   - 经验 > 0 → `∞`，被 `if (percent > 1) percent = 1` 夹成满格 → **条长度永远不变**
   - 经验 = 0 → `NaN`，两个 if 都拦不住 → 进度条宽度算出 `int.MinValue` 这种非法值
2. **服务端（更严重）**：`PlayerObject.GainExp()` 的升级循环
   ```csharp
   while (experience >= MaxExperience) { Level++; experience -= MaxExperience; RefreshLevelStats(); }
   ```
   `MaxExperience = 0` 时条件恒真、且 `experience` 每次减 0 从不减少 ——
   会一路把等级加到 **65535** 才被 `if (Level >= ushort.MaxValue) break;` 拦住。
   **每次获得经验都要空转 6.5 万次**，挂机打怪时服务端会明显卡顿。

### 已修复的 4 处

| 文件 | 改动 |
|---|---|
| `Server/MirObjects/PlayerObject.cs` | `GainExp()` 中在 `if (Experience < MaxExperience) return;` **之前**插入 `if (MaxExperience <= 0) return;` |
| `Client/.../MainDialogs.cs` | 经验条：`MaxExperience <= 0` 按满格处理，并加 `IsNaN/IsInfinity` 兜底；百分比文字满级显示 `100%` |
| `Client/.../MainDialogs.cs` | 负重条：`背包负重 = 0` 时直接不画，避免同类除零 |
| `Client/.../HeroDialogs.cs` | 英雄信息面板的经验条做同样处理 |

> 顺带说明：经验条用的素材（`Prguse.Lib` 的 index 8，1024 分辨率，1004×8）经核对与代码
> 里写的位置、尺寸**完全吻合**，并非资源版本错位，无需替换素材。

### 如果角色等级已经被刷到 65535

服务端旧版逻辑可能已经把等级刷上去了，用 GM 命令改回来即可（例如 `@等级 100`）。

- 经验条上方的百分比数字应是正常数值（不再是 `∞%` / `NaN%`）
- 角色等级不应在打怪后突然跳变

## 七、新人腕力为 0 + 背包异常蓝条（2026-09-28 第二次修复）

**现象**：新角色腕力/负重全为 0，基础衣服武器穿不上；打开背包时底部出现异常蓝色长条。

**根因（两个现象同一个原因）**：117 的配置文件 `Configs\BaseStats*.ini` 用的段名是
`[背包重量] / [负重] / [腕力]`，而 110 源码的 `Stat` 枚举名是
`背包负重 / 装备负重 / 腕力负重`。启动加载时对不上号 → 这三项 = 0。

- 腕力负重 = 0 → 任何武器/衣服都超重，穿不上
- 背包负重 = 0 → 背包对话框的负重条 `CurrentBagWeight / 0` 得到 ∞/NaN，
  `(int)NaN` 在 x86 上变成 int.MinValue → 画出异常蓝色长条

**修复**：10 个配置文件（BaseStats5 职业系 + HeroBaseStats5）三个段名已改名对齐 110 枚举。
原 117 版配置备份在 `Configs\BaseStats.bak-117\`。

**另加固**（防止以后再出现同类除零）：
- `Client/.../InventoryDialog.cs` 背包负重条：`背包负重 <= 0` 时直接不绘制
- `Client/.../CharacterDialog.cs` 人物面板：经验百分比 `MaxExperience <= 0` 时显示 100%

**注意**：BaseStats 的 ini 是**服务端启动时读取**的，改完必须重启服务端才生效。
