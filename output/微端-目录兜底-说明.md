# 微端：接口优先 + HTTP 目录兜底（2026-11-14 定稿）

## 一、行为

每个文件按下面的顺序取，**先能拿到哪个就用哪个**：

```
1) 微端接口：  GET http://<Host>/resource?f=Data/Monster/000.Lib      （主）
2) HTTP 目录： GET http://<DirHost>/Data/Monster/000.Lib               （兜底，仅当 1 连不上）
```

**兜底只在“接口服务器连不上”时触发**：

| 情况 | 是否改用目录 |
|---|---|
| 连接被拒 / DNS 失败 / 断连 / 超时（15s） | ✅ 改 |
| 502 / 503 / 504（网关或上游不可用，玩家开代理/加速器时常见） | ✅ 改 |
| 404（接口明确说“没这个文件”） | ❌ 不改，按原逻辑记「服务端没有」 |
| 403 / 其它 4xx | ❌ 不改 |

确认接口不通后进入 **5 分钟冷却**：这段时间里所有文件直接走目录，不再逐个等超时
（否则几千个文件 × 15 秒会把启动拖到几十分钟）。冷却结束会重新试一次接口。

## 二、配置（`Mir2Config.ini [MicroClient]`）

| 键 | 说明 |
|---|---|
| `Host` | 微端接口服务器（`/resource?f=` 那台） |
| `IndexHost` | 清单来源；留空 = 用 `Host` |
| **`DirHost`** | **HTTP 目录兜底服务器**（网站根 = 资源根）；留空 = 不启用兜底（行为与改动前完全一致） |
| `FileAtRoot` | True = 只走目录（不用接口）；一般填 False |
| `Timeout` | 建议 8000，接口不通时能更快切换到目录 |

当前部署：

| 客户端 | Host（接口） | IndexHost（清单） | DirHost（目录兜底） |
|---|---|---|---|
| `E:\micromir2` | `http://127.0.0.1:8888` | 同 Host | `http://219.138.108.82:65534` |
| `D:\龙之传奇` | `http://uk.frp.one:19999` | 同 Host | `http://219.138.108.82:65534` |

清单同样是三级兜底：`IndexHost` → `Host` → `DirHost`，每个地址先试 `/resindex`，
再试 `/resindex.txt`（纯静态站没有 `/resindex` 重写，靠这个文件顶上来）。
**所以在远端根目录丢一份 `resindex.txt`，接口机和主服全挂也不影响玩家。**

## 三、实测

`Tools\MicroUrlTest`（反射调用真 Client.dll，真下载、真落盘）—— **42 项断言全过**：

- 接口不通（502）→ 日志 `微端服务器连接不通，改用 HTTP 目录直取` → 下载成功，md5 与本地一致
- 接口回 404 → **不**改走目录，不落盘目录版本（语义隔离正确）
- 纯静态模式（`FileAtRoot=True`）目录地址 = `Host/相对路径`
- 302 之后不再有中转：目录链路首跳就是 `200`，无 `Location` 头
- `Range` → `206` + `Content-Range`，断点续传可用
- 配置 `Load → Save` 往返，`IndexHost` / `FileAtRoot` / `DirHost` 都还在（不会被退出重写抹掉）

远端整站全量：**3652 / 3652 = 100.00%**。

## 五、建议做的一件事

把 `D:\Mirserver\ClientResources\resindex.txt`（76KB）上传到远端根目录。
这样即使 `uk.frp.one:19999` 长期不通（现在就是 6 秒超时不可达），
玩家也能从远端拿清单 + 从远端下文件，本机 8888 可以完全关掉。

## 六、注意

1. 远端是 Linux，**文件名大小写敏感**，上传不能改名
2. 老客户端（旧 `Client.dll`）不认 `DirHost`：它的 `Host` 若指向已停的服务器就会下不到资源（游戏本身照常能玩）。随 `Client.dll` 一起发 ini 即可
3. 素材增删后重生成清单并上传：`python D:\mir2-20241027\Tools\NginxMicroDeploy\gen_resindex.py`
4. 远端不要配 SPA fallback（缺失返回 HTML 会被写成 `.Lib`），不要开 gzip
