# 微端「客户端直连远端下载」部署包

> 目标：玩家客户端直接请求 `http://219.138.108.82:65534`，全量素材从远端下载，
> 主服 8888 不再参与文件传输（只留作备份/回退）。

---

## 一、包里有什么

| 文件 | 放到哪里 | 作用 |
|---|---|---|
| `resindex.txt` | 远端**网站根** | 资源清单 3652 条，客户端第一个请求就是它 |
| `nginx-micro-remote.conf` | 参考用（不要直接覆盖现网） | 远端 nginx 要加的 `map` + 3 个 `location` |
| `Data/` `Map/` `UI-/` | 远端**网站根**（保持同结构） | 远端当前缺的 33 个文件，13.78 MB |

## 二、远端要做两件事

### 1. 把文件解压到网站根

解压后目录应变成（和现有结构合在一起，不要嵌套）：

```
<网站根>/
├── resindex.txt              ← 新增
├── Data/
│   ├── StateItem.Lib         ← 补
│   ├── ItemFilter.txt        ← 补
│   ├── 自定义素材.Lib         ← 补
│   └── Map/WemadeMir2/Smtiles.Lib  ← 补
├── Map/  (D421 D601 D603~D606 D608~D610 D710 D711 Utopia2)  ← 补
└── UI-/  (skin.ini + Skin/uk/Prguse/*)                      ← 补
```

**必须保留原始大小写**（远端 Linux 区分大小写：`Data/Effect.Lib` ≠ `Effect.lib`）。

### 2. nginx 加配置

打开 `nginx-micro-remote.conf`，把两段内容贴进你现网的配置：

- **A 段** `map $request_uri $micro_rel { ... }` → 放进 `http { }`
- **B 段** 三个 `location` → 放进对应 `server { }`

改一行路径：配置里的 `/www/mir2res` 换成你的实际网站根（共 4 处）。

```bash
nginx -t && nginx -s reload
```

> 若远端是宝塔面板：网站 → 设置 → 配置文件，粘贴后保存即可（宝塔会自动 reload）。

## 三、主服这边怎么切

玩家客户端的 `Mir2Config.ini`：

```ini
[MicroClient]
Enabled=True
Host=http://219.138.108.82:65534
Timeout=15000
Concurrency=4
```

想保留主服做备源（连不上远端时自动切换，顺序有意义）：

```ini
Host=http://219.138.108.82:65534,http://你的主服地址:8888
```

依据（客户端源码既有行为）：
- 地址池**只做故障转移**：连接失败 / 断流 / 5xx 才换下一台
- **404 不切换**，会被判「服务端确实没有」并在本次运行内永久拉黑
- 清单只加载**第一台**的，切服务器不会重拉 → 两台资源必须严格一致

## 五、这套配置已做的实测（不是推测）

同构配置 + 真客户端 `HttpClient`（与 `ResourceDownloader.SharedClient` 同参数）：

- `/resindex` → 200 `text/plain`，3652 条
- 路径式 `04%20L.Lib` → 200 / 351930B，**md5 与本地一致**
- 路径式 `自定义素材.Lib` → 200 / 61583B，md5 一致
- 旧式 `?f=` → 302，`Location` 原样保留 `%20` / `%E8`，跟随后 200 + md5 一致
- 断点续传：302 之后仍 `206` + `Content-Range` 正确，只返回剩余 50 字节
- 404 透传；`..` 穿越 404；空参数 404
- **全量 3652/3652 = 100.00%**

## 六、三个必须记住的坑

1. **不要配 SPA fallback**（缺失文件返回 `index.html`）→ 客户端会把 HTML 写成 `.Lib`，图库直接废
2. **不要开 gzip** → `.Lib`/`.map` 本身已压缩，白耗 CPU 还可能干扰 Range
3. **素材有增删必须重生成清单**：主服 `python D:\mir2-20241027\Tools\NginxMicroDeploy\gen_resindex.py`，
   然后上传覆盖远端的 `resindex.txt`。客户端本地已有的文件不会重下，这点和自带服务一样
